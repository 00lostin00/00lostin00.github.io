第1章 计算机系统概述

1.1 计算机发展历程

电子管、晶体管、集成电路、超大规模集成电路构成常见硬件发展主线；软件从机器语言、汇编语言发展到高级语言及系统软件。该节在王道目录标为带星参考内容，先识别基本阶段，不应挤占性能与系统层次的学习时间。

1.2 计算机系统层次结构

程序执行过程

预处理处理宏与包含等；编译把高级语言转换到较低层次表示；汇编生成目标机器代码；链接组合目标文件和库、处理符号引用与地址安排。考试题中不要把“汇编”与“链接”互换。

ISA是软硬件接口。它规定软件可见的指令、寄存器、数据类型、寻址与异常等规则。数据通路、控制信号怎样实现这些规则，属于实现层面。相同ISA的机器可以有不同主频、CPI和内部组织。

图源：强化讲义PDF第2页。ISA连接软件与硬件实现层。操作系统属于软件，不能把它与ISA等同。

存储程序与五大部件

计算机系统由硬件和软件组成。经典硬件分类为运算器、控制器、存储器、输入设备、输出设备。CPU通常包含运算、控制和寄存器等部分。

指令和数据都以二进制存储，不能只凭位型区分。CPU根据访问目的、当前阶段以及相应控制方式解释取出的内容。“存储程序”强调把程序也作为存储内容，使机器能连续取出并执行。

选择题切入点：题目问“完整系统”要想到软硬件；问“五大部件”按经典分类；问CPU组成时不要把主存算进CPU。

从一条访存指令看五大部件

以 LOAD R1,[A] 为例：PC给出指令地址，主存读出指令，经IR译码；控制器发出求地址和读存储器信号；地址A送到地址通路，读回的数据沿数据通路进入R1。若执行 ADD R1,R2，ALU接收操作数并把结果写回；若执行分支，改变的是后续取指地址。数据与指令的二进制形式没有天然区别，区别在于访问阶段及控制解释。MAR回答“在哪里”，MDR回答“搬什么”，IR回答“现在执行什么”。

三种字长不能混为一个量

机器字长通常联系CPU整数运算的基本位数；指令字长是指令编码占多少位；存储字长是一个存储单元所含位数。三者可能不同。若按字节编址，32位地址对应最多个字节地址；若按32位字编址，同样32位地址对应个32位字。容量结论相差4倍，因此先找编址单位。

1.3 计算机的性能指标

程序执行时间

是实际执行指令数，是该程序对应的平均每条指令周期数，是主频。

推导思路：执行多少条 × 每条占多少周期 = 总周期；再乘每周期多少秒。知道这个过程，就不容易把主频乘到分子。

指标 问的是什么 容易误用的地方
主频 每秒多少周期 不等于每秒指令数

MIPS 每秒多少百万条指令 不能脱离任务比较不同ISA的性能

第2章 数据的表示和运算

2.1 数制与编码

位型与真值

同一个8位位型11111111，按无符号数读是255，按补码整数读是-1。位没有变，解释规则变了。十六进制只是位型的紧凑书写，不自动规定有符号性。

编码，总共位整数 真值范围 读法
无符号 全部按正位权
原码 最高位标符号，其余读绝对值
补码 最高位权，其余正权

原码有正零、负零，补码零唯一。反码负数由对应正数的全位取反得到，也有两个零。移码按“真值+指定偏置”计算；只有偏置为时，才可直接用同宽补码翻转最高位。

例： 8位BEH，，补码真值。反过来求-66的补码，就算，再写成BEH。

进制、扩展、截断

二进制转十六进制按四位分组；转八进制按三位分组。整数端从小数点向左分组，小数端向右分组。不足位只能在外侧补零，不能改变小数点位置。

位宽改变的三条规则：

  • 无符号扩展：高位补0。
  • 补码有符号扩展：高位复制原符号位，保持真值不变。
  • 截断：保留低位；真值是否改变，取决于被截掉的内容和目标解释方式。

做C类型题的表格：

参与表达式 先考虑整数提升与通常算术转换 再计算 最后判断比较结果

注意：表达式中的char/short常先提升成int，不能看到8位变量就把整个C表达式当成8位加法。机器指令题则按题设运算宽度计算。对真实C语义，有符号溢出不能普遍解释为自动回绕；考试明确给定位宽、补码及机器指令行为时按该机器模型求解。

定点小数的位权与补码边界

若共位、最高位为符号位，其余位为小数，则补码，范围。1.000是−1；1.111是−1/8，不能按“符号位+绝对值”读成−7/8。原码则按符号与绝对值分开读，有两个零，范围。所谓“补码能多表示一个负数”来自符号位负权，而不是额外增加一个编码。

移位与ALU

逻辑右移高位补0，算术右移复制符号位。补码算术右移可能损失低位精度，负数结果不应直接套“截去小数部分的除法”。逻辑左移与算术左移的移位动作可相同，但有符号解释下要额外判断溢出。

加法器电路题：每位和位由本位A、B和进位决定；串行进位等待前一级，先行进位通过生成/传递关系缩短等待。若题目要求门延迟，要按给定逻辑级数和门延迟算，不能把“位数”直接当“时间”。MUX从输入中选一路；译码器把输入编码转换为一组选择信号，两者作用不同。

乘除法：先定算法和寄存器含义

无符号乘法可理解为按乘数位决定是否加被乘数，再移位累积；位乘位，完整乘积最多需要位。有符号乘法必须处理符号，可依题设采用补码乘法或先求绝对值再定符号。

逐步执行题用表：“轮次｜部分积/余数｜乘数或商｜本轮操作｜移位后的值”。每轮明确是先加后移、先移后加，以及整体联合移位哪些寄存器。

Booth补码乘法常通过相邻乘数位决定加、减或不操作；规则取决于题设对相邻位顺序的书写，必须对照表使用。除法的恢复余数、不恢复余数算法也不要混表。

结果验算： 。余数符号与商的取整方式按题设；无符号整数除法应满足。除0、商超过目标位宽都要先检查。

第位和。取、，则，其中加号表示逻辑或。展开有。串行进位等待低位产生进位；先行进位把依赖展开，门数与扇入代价增大，传播层数缩短。若教材把P定义为逻辑或，配套公式也必须按该定义使用。

减法把与Sub异或，令：Sub=0做A+B；Sub=1做。x86式借位标志可写。OF是最高位进入与离开进位的异或；ZF看截断结果是否全0，SF取结果最高位。

先做符号扩展，再在多一位的结果上看双符号位：00为正且未溢出，11为负且未溢出，01为正溢出，10为负溢出。例：4位补码7+3，扩展后00111+00011=01010，双符号01，超出4位补码最大7。最终4位1010虽表示−6，真实和仍为10，溢出不能被位型掩盖。

精度题抓临界值： binary32能精确表示内的全部整数，但更大区间并非一个都不能表示；在某些范围中只可表示间隔为2、4等的整数。不要把“超过临界值”写成“一律不精确”。

本章验算清单

先写位宽、符号性、小数点位置 → 写位型 → 做硬件运算 → 分别解释真值、OF、CF → 检查边界。负数补码、最小负数、符号扩展、有符号/无符号比较是需要反复练熟的基础。

浮点舍入：保留位、保护位与粘滞位

单精度规格化数有24位有效二进制数字（包含隐藏1）。最近偶数舍入用保护位G、舍入位R、粘滞位S判定：被舍部分大于半个ULP则进位，小于则舍去，恰好一半则让保留部分末位变为偶数。S是其后所有舍弃位的逻辑或。例只保留4位有效数，1.0101000恰为中点，保留1.010；1.0111000也是中点，进为1.100。不能把所有“5”都进位。

浮点加减依次做对阶、尾数相加减、规格化、舍入、溢出判断。小阶向大阶对齐；减法抵消可能左规；舍入进位可能再次右规并增加阶码。不要在对阶时提前丢光所有保护信息。

3.1 存储器概述

先认清存储层次

寄存器、Cache、主存、外存形成速度与容量的层次。Cache利用时间局部性和空间局部性缓解CPU与主存速度差异；虚拟存储侧重地址空间、保护与按需调页。Cache缺失、TLB缺失、缺页是三种不同事件。

存储介质 关键机制 做题抓手
SRAM 触发器等静态单元，无需像DRAM那样刷新 常用于Cache，速度与成本
DRAM 电容存储，需刷新，行列地址复用 主存、刷新开销、地址引脚

3.2 主存储器

交叉编址与存储带宽

低位交叉常把体号放在低位，使连续地址轮流进入不同存储体；高位交叉把连续一段地址放在同一体内。能否提高实际带宽还取决于访问模式、存储周期、总线和启动间隔。

若每体周期、相邻访问启动间隔，要持续每发起一次且不撞回尚未恢复的体，常见条件为。理想顺序读个单位常写成，前提是题设确实允许重叠且无其他瓶颈。

刷新题先找刷新周期、总行数、每行刷新所占时间；分清集中、分散或异步刷新。不能把刷新一次的行数误当成全部存储单元数。

SRAM与DRAM、刷新与周期

SRAM用双稳态电路保存位，通常无需刷新，常用于Cache；DRAM用电容电荷保存位，需刷新，常用于主存。二者断电均丢失数据。ROM是非易失性存储器类别，不能将“随机访问”与“可随意写入”画等号。

存取时间是完成一次读/写所需时间；存储周期是允许连续启动两次独立存取的最短间隔，含恢复等限制，通常不小于存取时间。DRAM行列地址分时复用，地址引脚数不直接等于总地址位数。位芯片有个单元，若行列均分，各需11位地址并分时传送；4位数据宽度不增加地址引脚。

若4096行需64ms刷新一遍，分散到每行一次的最大平均间隔为。若每次刷新用100ns，集中刷新总占，一轮死区比例0.64%。集中、分散、异步刷新对可用访问时间的安排不同，算题前先定方式。

交叉存储与总线联合计时

低位交叉用低地址位选存储体，连续地址轮流落到不同体；高位交叉使连续一段地址集中在同一体。若每体存储周期T、相邻启动间隔τ，要连续流水启动应有。读n个连续字的理想总时间，前提是无存储体冲突、总线可流水且题目允许数据接续传输。

强化讲义PDF第84页的题：4体交叉、每体40ns，主存块与总线均8B，地址发送10ns，数据传送10ns。CPU读一个存储单元并回填其所在8B块时，块恰好只有一次8B传送；无须为同一块并行启动4个体。按阶段串行模型总计10+40+10=60ns。“4体”不能机械变成“除以4”。若块改为32B且每10ns可启动一体，必须再画时间轴，判断连续4次读出能否同总线传送重叠。

ECC校验的有效范围

奇偶校验能检出奇数个位翻转，不能保证检出偶数位错误，也不能定位出错位。汉明码若m位数据、r位校验，要为无错与每个单错位置保留不同综合征，故。例如8位数据最少4位校验，组成12位；常规汉明码纠正1位错，额外全局奇偶校验可扩展为SECDED。不能把“满足位数不等式”当成已经设计出了校验矩阵。

3.4 外部存储器

磁盘访问时间

转速 rpm，一圈秒；均匀随机到达假设下，平均旋转等待半圈。传输时间按传输字节数/对应速率求；只求一个扇区时可结合每圈扇区数计算。

容量通常为盘面数×每面磁道数×每道扇区数×每扇区数据字节数。盘片双面、是否有保留面、地址信息是否计入有效数据容量，逐项看题设。

顺序、随机访问与SSD

7200rpm每转8.333ms，平均旋转等待4.167ms；若每磁道200扇区，每扇区512B，读一个扇区传输时间约41.667μs。给定平均寻道5ms，则随机读一个扇区约9.208ms（未计控制器开销）。连续读取一整道不能每扇区重加一次平均寻道与旋转等待。

SSD以页读写、块擦除，覆写一般要异地写入并由FTL维护逻辑到物理映射；垃圾回收搬迁有效页并擦块，会产生写放大。磨损均衡分摊擦写，不能理解成每次写入都立即擦除对应原块。教材§3.4将外存放在存储系统章，这里与I/O计时交叉复习。

3.6 虚拟存储器

虚拟地址、TLB、页表、Cache串起来

页大小字节时，虚拟地址拆为“虚页号VPN｜页内偏移p位”；页表或TLB把VPN转换成物理页框号PPN，偏移不变。

这是便于解题的串行逻辑模型；有的Cache可与TLB并行索引，有的题给多级页表，以具体结构为准。

三种失效的区别： TLB缺失只说明快表没有翻译；Cache缺失只说明所需数据块不在Cache；缺页说明页面当前不在主存。前两者都不必然访问磁盘。

算访问次数：按“当前路径实际经过几次查找”列树，再乘概率。一级页表、无快表、页面在主存时，若一次读取需要先访存查表再访存取数，就是两次主存访问；多级、缓存和并行会改变计数。

页表到Cache的一条完整访问链

先将虚地址拆为VPN与页内偏移，再查TLB；TLB未命中可查到有效页表项，属于TLB miss而非缺页。有效位为0才需缺页处理。拿到PPN后保留原页内偏移形成物理地址，再按物理Cache的Tag/组号/块内偏移访问。脏页换出才多一次外存写入，换入本身还要读盘，通常远慢于纳秒级命中。

例32位虚地址、4KiB页、4B页表项：VPN20位，单级页表有项，占4MiB。两级10/10/12划分时，每级表页均有1024项，占4KiB，但按需建立二级表；不能把所有进程都按完整4MiB常驻页表来算。

第4章 指令系统

4.1 指令系统

分清四种长度

机器字长：CPU自然处理数据的宽度；指令字长：一条指令多少位；存储字长：一个存储单元的位数；地址长度：可编码地址的位数。它们可能相同，也可能不同。

定长指令便于对齐取指，不意味着一条指令只做一步；RISC常采用规整格式与load/store组织，但具体指令行为仍以ISA为准。

指令格式与扩展操作码

若指令总长、每个地址字段位，有个地址字段，则剩余位可用于操作码和其他控制字段。实际题目若另有寻址模式等字段，还要扣掉。

扩展操作码题：画前缀树，从长地址指令开始分配；某前缀已用于短操作码，就不能同时成为另一个完整操作码的前缀。每剩一个长度的前缀，多扩位就可得到个新编码。逐层扣除已用前缀，不要把不同长度的编码直接相加。

扩展操作码：用前缀树分配，而非反复相减

16位指令，地址字段4位，三地址指令有4位操作码。若已用8种三地址指令，余8个前缀可扩展；二地址指令每个前缀再接4位，共128种候选。若用掉100种二地址指令，剩28个8位前缀，可再产生448种一地址指令。先画“每少一个地址字段释放4位”的分支树，并确认长短操作码没有前缀冲突。若题目保留特殊编码，须先扣除保留项。

调用、栈与返回

调用通常需要记录返回地址；栈保存局部数据、参数或现场，但具体哪些寄存器由调用者/被调用者保存由约定决定。读汇编时跟踪SP、返回地址寄存器和保存位置，别默认所有机器都采用同一栈方向或调用规范。

对递归题，每层栈帧大小乘同时存活层数，而不是乘调用总次数。返回后SP应按约定恢复，可作为验算。

MIPS指令语义与跳转编码

add rd,rs,rt把两寄存器之和写入rd；addi rt,rs,imm写入rt；lw rt,off(rs)读写rt；sw rt,off(rs)把rt写入该地址。beq/bne比较rs与rt。分支目标；J型伪直接跳转目标由PC+4高4位、26位字段、两个0拼接。

例分支位于1000H，目标0FF0H，先算基准1004H，差值−14H=−20B，再除4得−5，16位补码字段FFFBH。反代1004H+(−5)×4=0FF0H。把−20直接编码进字段会跳错4倍。

数组、循环、函数调用统一成地址计算

C按行存储二维数组int a[R][C]，假定int为4B，a[i][j]地址为base+4(iC+j)。例C=5，a[2][3]偏移52B；MIPS代码需计算i×C+j后再左移2位。先写元素下标，再换字节，防止遗漏行跨度。

过程调用要解决参数、返回地址、局部变量与被保护寄存器。典型32位x86栈向低地址增长，push ebp; mov ebp,esp后，旧ebp位于[ebp]、返回地址在[ebp+4]，栈上传参可在[ebp+8]起；本地变量多为负偏移。此表依调用约定和序言，优化后可能省略帧指针，不能凭固定偏移猜任意代码。MIPS通常用jal保存链接寄存器，嵌套调用前要保护将被覆盖的返回地址。

4.4 CISC和RISC的基本概念

CISC强调较丰富的指令及寻址能力，RISC通常使指令格式更规整并采用load/store。应从指令集特征判断类别，再讨论具体CPU实现；流水线、缓存和内部微操作不是某一类指令集的专属。

RISC/CISC判断的边界

RISC常见特点是规则编码、较少寻址方式、load/store和较多寄存器，便于流水；不保证每条指令都一周期，也不意味着只能硬布线控制。CISC也能采用流水线和内部微操作。相同程序性能仍回到N、CPI与时钟周期一起比较。

5.2 指令执行过程

取指周期取得指令并更新PC，间址周期按寻址方式取得有效地址，执行周期完成指令功能，中断周期完成中断响应入口操作；不是所有指令都经历每一种周期。指令周期由若干时钟周期组成，多周期实现的不同指令所需周期数可不同。PC的增量由指令长度与编址单位决定，不能无条件写成1或4。

5.3 数据通路的功能和基本结构

数据通路题：先写语义，再沿图走

例： load的语义是“基址+偏移求EA，读内存，结果写目的寄存器”；store是“求EA，把源寄存器数据写到内存”，没有把结果写回通用寄存器这一步。

按这个顺序填控制表：

  1. 列出读哪些寄存器、写哪个寄存器、是否访存。
  2. 确定ALU的两个输入和运算。
  3. 确定写回来源是ALU、存储器还是其他来源。
  4. 确定PC顺序前进还是分支/跳转。
  5. 给MUX选路、寄存器写使能、存储器读写、ALU控制赋值。

无关信号才可写X。例如不写通用寄存器时，写回MUX可能无关；但MemWrite若随意写X，可能产生意外存储，不能因为“该指令不访存”就把它当无关。

单总线、多周期：先检查资源冲突

单条内部总线同一时刻通常只能由一个源驱动，多个目的寄存器可在条件允许时同时接收同一个值。ALU要做双操作数运算时，常需要暂存器保存一个输入。

排微操作步骤：写出不可省的操作 → 标依赖 → 检查总线谁输出、谁接收 → 标访存等待 → 再合并能并行的步骤。不能把同一条总线安排成“R1输出A、R2同时输出B”。

单总线微操作的可执行性

先给每个时钟列一个总线源；多个寄存器可接收同一个值，但不能让两个不同源同时驱动单总线。若ALU一端接暂存器Y、另一端接总线，执行R1←R2+R3可排：T1为R2out,Yin；T2为R3out,ADD,Zin；T3为Zout,R1in。若图有PC专用加法器，PC递增可能并行；若PC递增也要借用同一ALU，则必须排开。把控制信号写对还不够，需检查数据沿图确实能到达。

5.4 控制器的功能和工作原理

控制器：机器指令与微指令不是同一层

硬布线控制通过组合逻辑、状态和时序等产生控制信号；微程序控制从控制存储器读取微指令，逐步给出控制信号和后继地址。微指令位于控制实现层，不是用户程序中的机器指令。

计算题：微指令字长=操作控制字段+判别字段+下址等字段；控存容量=微指令条数×每条位数。水平型可并行控制较多操作，字段编码可缩短字长但增加译码约束。填字段前先判断哪些微操作互斥、哪些可能同周期发生。

微指令字段编码的节省

若一组有5个互斥微命令，且允许本组全不选，需要6种状态，字段至少位。另两组有3和2个互斥命令，分别还需2、2位，总7位；若直接编码这10个控制命令，需要10位。字段分组必须保证同一字段内的微命令不会要求同时发出。控存有256条微指令、每条32位，容量8192bit=1KiB；8位微地址不是8字节控存。

5.5 异常和中断机制

分支、异常与并行概念

分支题先找比较和目标计算在哪一级完成、是否预测、预测失败冲刷哪些年轻指令。停顿和冲刷可能有重叠，不要把几个罚时数字重复相加。

异常由指令执行相关事件引起，例如缺页、非法指令、系统调用等；外部中断由设备或时钟等引起，与当前指令的执行一般异步。返回地址是重做当前指令还是继续下一条，由异常种类和体系结构规定。

超标量关注一周期发射多条指令；多核是多个处理核心；硬件多线程切换或交错线程以利用资源；它们不能互当同义词。

异常返回的三种位置

故障发生在指令完成前，可恢复时常重新执行故障指令，如缺页；陷阱在指令完成后报告，通常返回下一条，如某些调试/系统调用约定；终止类可能无法恢复。外部中断一般在指令边界响应。具体断点依ISA和题设，不能断言所有异常都返回PC+4。硬件一般保存必要断点/状态并进入处理入口；通用寄存器现场常由软件按需要保存。

典型五段为IF取指、ID译码/读寄存器、EX执行、MEM访存、WB写回。不是每条指令都做实际内存读写，也不是每条都有通用寄存器写回。

5.7 多处理器的基本概念

并行题分清对象

SISD是单指令单数据；SIMD对多数据执行相同指令，适合向量化；MIMD让多个处理单元独立执行不同指令流。多核可组成共享内存多处理系统，但每核有私有Cache时需维护一致性。硬件多线程改善资源利用与隐藏等待，不保证单线程延迟下降。超标量是动态多发射的一类；VLIW通常由编译器静态组织并行操作，不能把“每周期多条”都归于同一种调度机制。

第6章 总线

6.1 总线概述

1 总线概述
先分清总线传的是什么

王道第六章把总线单独讨论。数据线传送数据、指令、状态或中断类型等信息；地址线用于指定主存单元或I/O端口；控制线说明读写、请求、应答及定时等。地址线宽度限制可编址单元数，数据线宽度决定一次传送的基本数据量，不能用数据线宽度推主存容量。

总线的分时性指同一时刻通常只允许一个主设备占用；共享性指多个部件可连接在同一组传输线上，并不表示各设备可同时驱动数据线。主设备是发起本次事务并取得控制权的一方，DMA控制器也能成为主设备。

时钟、周期与带宽逐个换算

设总线宽度W位，总线时钟频率f，每周期有效数据传输r次，理论峰值带宽为。W=64、f=100MHz、双沿传送，峰值1.6GB/s。若题给“一次总线周期包含4个时钟周期”，且每个总线周期只传一次64位，则有效带宽200MB/s。双沿次数和总线周期长度不应重复乘除。

有效带宽要以有效数据字节数除以全部事务耗时，地址、等待、仲裁等开销是否计入按题设。MB默认题设的十进制，MiB是B，结果必须注明。

2 总线事务和定时
总线事务与定时

一次总线事务通常包括申请分配、寻址、数据传送和结束。总线时钟周期是统一时基；总线周期是一次基本传送所占时间；事务可能含多个基本传送。突发传送先给起始地址，随后连续传多个数据，摊薄寻址开销。

同步定时以统一时钟限定采样；异步定时以请求/应答协调，不要求设备速度相同。异步并非“没有时序约束”。不互锁请求方发出请求后不等待应答撤销请求；半互锁一方撤销动作依赖对方；全互锁双方撤销动作均受对方信号约束。读波形时先写每个信号上升、下降的触发条件，避免只背名称。

2023统考题：非突发传送如何计时

王道§6.2选择20，教材第288页：数据总线64位，总线时钟1GHz，每个地址传送1周期，不支持突发；主存每次准备64位需6ns，块大小32B。求读一块耗时。

**想法：**先由块和总线宽度算4次数据传送。题设不支持突发，每次都重新传地址并等待主存，不能只付一次6ns。

**步骤：**1GHz对应1ns；一次传8B耗“地址1ns+准备6ns+数据1ns”=8ns；32B需4次，共32ns，选D。

**变式：**若允许连续突发，后续字准备可流水，就必须按首次延迟和后续间隔重画时间轴。只改“支持突发”一句，原式4×8就未必成立；更不能无条件套1+6+4。

**验算：**32B/32ns=1GB/s，低于64位×1GHz=8GB/s的理论峰值，差距来自地址和主存等待。

6.2 总线事务和定时

第7章 输入/输出系统

7.1 I/O系统基本概念

I/O系统由外部设备、I/O接口、控制方式及相关软件协作构成。设备控制器负责连接设备与主机；数据传送方式主要有程序查询、中断、DMA。外设机械动作与CPU可以并行，CPU执行传送或服务程序本身仍需消耗处理时间。

7.2 I/O接口

接口不是设备本体，端口不是一根线

I/O接口包含数据缓冲、状态/控制寄存器、地址译码与控制逻辑等；端口通常指其中可寻址寄存器。CPU通过读状态、写控制、读写数据与外设交互。

图源：强化讲义PDF第206页。按线读：地址线选寄存器，数据线传数据，控制线说明读写和状态协调。DMA传输期间，由获总线控制权的相应主设备提供主存地址，不应理解为每个数据字仍由CPU发起普通load/store。

7.3 I/O方式

带宽题先找“每次传多少”和“每秒多少次”

数据总线宽度32位，每个100 MHz时钟周期传一次，理论数据带宽 B/s=400 MB/s。若每次事务要4周期且只有一次32位数据传送，则有效数据带宽100 MB/s。若双沿传输或突发传输，以题设有效传输次数为准。

抓三个边界：主频是否就是总线频率；传输周期与时钟周期是否相同；求理论峰值还是包含地址、握手、等待后的有效数据带宽。

同步总线依赖统一时钟约定；异步总线以握手等协调；半同步允许等待。仲裁解决多个主设备争用总线，优先级、响应速度和饥饿等按具体方案判断。

中断流程与优先级

常见流程可整理为：检测并响应 → 保存断点/必要状态并转入入口 → 软件保存需保护的现场 → 服务 → 恢复现场 → 中断返回。哪部分硬件完成、哪部分软件完成、是否开中断，依体系结构和题设。

单字缓冲来不及服务时，光算占用率不够

教材第300页例7.2：CPU500MHz，设备40MB/s，接口一次存32bit，每次中断响应与处理至少400周期。外设填满4B需要，CPU每次服务至少，服务比来数慢8倍，单字中断方式无法保证不覆盖。CPI=4不能再乘400，因为400已经是周期数。若题给的是400条指令，才需乘CPI。

增大缓冲并按块通知，可降低请求次数；用DMA搬块可降低CPU逐字服务开销。但块缓冲容量、传送启动延迟与设备持续流速仍应共同满足约束。

DMA两种频率、两种负担

设设备8MiB/s，DMA每次传4B，每块4KiB，则数据传送请求率/s，而完成中断率/s。若完成中断耗1000周期、CPU1GHz，仅完成中断占0.2048%；若每个4B搬运独占总线20ns，理论总线占用4.194304%。两个比例的分子不同，不能混算成CPU每传一个字执行一次中断。还需加初始化等题设开销。

停止CPU访存的成组传送、周期挪用与交替访问是不同争用模型。DMA占总线不必让CPU所有执行都停顿：命中私有Cache且无冲突的指令仍可能执行。题目明确“CPU停止工作”时，再按该模型计算。

嵌套中断：响应次序与处理优先级分开

设响应优先级1>2>3，处理优先级3>1>2，屏蔽位1表示屏蔽。同刻请求1和3，先响应1；进入1服务后，若允许嵌套且3尚待处理，3可打断1。在1服务时屏蔽字为110（屏蔽1、2，允许3），在2服务时010，在3服务时111。更高处理优先级可打断较低者，不等于一开始同时请求时必先响应它。若题目定义1为允许，屏蔽字逐位取反。

专题强化与自测

专题1：数据运算推导

1. 补码为什么能直接相加

w位寄存器只留下运算结果的低w位，所以硬件加法天然在模的范围内工作。负数-x编码成，就有。这解释了补码取反加一，也解释了最高位进位为何可以丢弃；丢掉进位不表示真值一定没有溢出。

对位型，无符号值是各位的正权和；补码把最高位权改为。因此同一位型的无符号值U与补码值S满足：最高位0时S=U；最高位1时。

例1：8位位型11110110。无符号值246；补码值246-256=-10。符号扩展到16位是11111111 11110110，新增8个1对应的无符号增量是65280，最后再减65536，仍为-10。零扩展则得到246。扩展方式由原数解释和操作规则决定，不能见到最高位1就一律补1。

截断反例： 16位补码00000000 11110110表示246，截到8位变成-10。截断保留了低位模值，没有保留原有真值。先问“要保持位型还是保持数值”，再判断转换。

小数不能套整数的最高位权

纯小数补码若写成，真值为，范围。例如1.101表示。整数11101与小数1.1101的小数点位置不同，数值不同；二进制点通常由约定确定，不额外占寄存器位。

2. 一次运算，同时判断有符号与无符号

例2：8位加法01111111+00000001。真正的加法产生10000000，无最高位进位。按无符号看127+1=128，没有越过255，CF=0；按补码看127+1超过127，OF=1。结果最高位SF=1，结果非零ZF=0。

变式：11111111+00000001。结果00000000并产生进位。无符号255+1越界，CF=1；补码-1+1=0，没有有符号溢出，OF=0；ZF=1，SF=0。

例3：8位10000000-00000001。硬件做10000000+11111111+1，低8位为01111111。无符号128-1=127，无借位；补码-128-1=-129不可表示，OF=1。若题目规定CF表示减法借位，则CF=0；有些实现使用“无借位进位”约定，必须先看题设。

加法有符号溢出：同号相加，结果异号。减法有符号溢出：被减数与减数异号，结果与被减数异号。二者也可用符号位进位与最高位进位的异或判断。

比较题为什么还要看OF？对补码A-B，A<B的条件是SF异或OF为1。上例SF=0、OF=1，仍正确判断-128<1。只看差的符号会错。无符号小于则看借位约定，不能借用SF。

从加法器看到超前进位

采用、时，，这里乘表示与、加表示或。展开得到。串行进位等待前一位，超前进位用展开式并行计算；二者结果相同，关键差别是延迟和硬件复杂度。题设若把P定义为或，按其定义推导，别混用两套符号。

3. 移位：动作、数值与误差分开判断

固定8位模型下，逻辑右移补0，算术右移复制符号位。位型11111011表示-5：逻辑右移得到01111101即125；算术右移得到11111101即-3。后者相当于对-2.5向负无穷取整，不等于C语言整数除法向零截断的-2。

左移时低位补0，高位丢弃。00100000左移2位得10000000：无符号32×4=128可表示；补码32×4=128不可表示。因此“左移k位相当于乘”要加上结果可表示的前提。硬件位移练习与C表达式的合法性分开处理；负数移位或有符号溢出不能凭固定宽度模型直接断言C程序结果。

浮点舍入

设一个教学浮点系统有效数共4位，包含隐藏首位，采用最近偶数舍入，阶码范围足够。

例8：。小阶码对齐后为0.0001，加得1.0101。它恰在1.010与1.011之间；保留位末位0为偶，结果选1.010。若原大数改为1.011，则和为1.0111，恰在1.011与1.100之间，选末位0的1.100。“偶”指所保留有效数的最低位为0。

一般用G、R、S位：G为第一丢弃位、R第二丢弃位、S为其后所有位的或；L为保留部分末位。最近偶数模式的进位条件为。G=0不进；G=1且后面有1说明超过半个间隔，进；恰好一半由L决定。舍入进位可能再次改变阶码。

例9：，有效数4位。对阶后第二数0.001，相加10.000，先右规成1.000×，再看需要舍弃的位。若先机械截成4位再规格化，会丢掉真正的有效位。

浮点加减的固定顺序：分类特殊值 → 比阶码 → 小数向大阶码对齐 → 有效数加减 → 规格化 → 舍入 → 必要时再次规格化 → 检查上下溢。相近数相减可能大量左规，体现有效数字损失；乘除法通常先运算阶码和有效数，再规格化与舍入，不需要像加减那样对阶。

专题2：地址与访问模拟

1. 先补基础：地址线为什么不总等于容量的对数

一个地址选一个编址单位。按字节编址的64 KiB空间有65536个地址，需16位；若同样64 KiB按16位字编址，则只有32768个字地址，需15位。容量除以编址单位，才是地址个数。

芯片8K×8表示8192个地址、每地址8位，共8 KiB，芯片逻辑地址需13位、数据线8根。DRAM行列地址复用时，封装物理地址引脚数不一定为13：把逻辑地址拆成行、列，在不同时刻送相同引脚，需配合行列选通信号。不要用引脚数直接断言寻址容量。

例1：用8K×8芯片组成32K×32存储器。每组4片并联扩位宽，4组扩地址深度，共16片。A0—A12接各片地址输入，A13—A14经译码选择一组，每组4片共用片选、分担32位数据。若按32位字编址，总共15位字地址；若CPU按字节编址且每字4字节，还需区分低2位字节选择，整个模块占128 KiB。两种“地址位数”回答的是不同问题。

地址范围与译码

例2：按字节编址，32 KiB模块起始地址0x80000。 32 KiB=0x8000字节，末地址=0x80000+0x8000-1=0x87FFF。减1是因为首地址已经占一个位置。0x88000是下一个地址，不属于本模块。

全译码检查足够多的高位以唯一选定模块；部分译码忽略某些高位，可能让多个地址访问同一个物理单元，出现地址重影。图中未接的高位不是凭空没有，而是选择逻辑不区分它们。

2. DRAM刷新与交叉编址：周期不能混叫

例3：1024行DRAM，要求64 ms内每行刷新一次。若每次刷新一行，均匀安排时两次刷新启动的平均间隔至多64 ms/1024=62.5 μs。若每次刷新占100 ns，则每个64 ms窗口共占102.4 μs，理论占用比例0.16%。这不是CPU读取一个字节的平均时间；正常访问、排队及刷新冲突还要按具体模型处理。多芯片若同一行可并行刷新，不能再乘芯片数。

集中刷新把刷新操作堆在一个时间段，形成较长不可访问区间；分散刷新与异步刷新如何命名、怎样穿插，以题目给定机制为准。做题始终抓住：多少行、每次刷新多少行、刷新窗口、每次占多久。

例4：4体低位交叉，单体访问周期100 ns，总线每25 ns接收一个字；连续读8字。低2位选体，因此连续字地址依次落在0、1、2、3体。相邻启动间隔25 ns，同一体再次启动间隔100 ns，恰好满足恢复时间。若首字100 ns后到达，8字总时间为100+7×25=275 ns。

换成2体，按25 ns启动会让同一体50 ns后又被访问，违反100 ns周期；持续均匀启动间隔至少为50 ns。若访问步长为4个字，4体低位交叉反复命中同一体，也失去连续地址的并行收益。先用“字地址模体数”列体号，才能决定能否套带宽公式。

6. 数组题：从地址序列推命中率

例8：int为4 B，数组64个元素，首地址按16 B对齐；Cache块16 B、数据容量128 B、直接映射，初始为空，仅访问此数组。一块放4元素，数组共16块，Cache8行。

顺序读一遍：每块首元素缺失，其余3个命中，共16缺失、48命中，命中率75%。紧接着从头再顺序读一遍：由于末8块占据Cache，前8块会把它们逐一换走，读后8块时又已不在，所以第二遍仍16次缺失。数组“已经访问过”并不意味着第二遍全部命中。

改成两层循环：外层遍历块，内层把同块4元素重复读两遍，再换下一块。每块8访问仅首个缺失，整程16缺失/128访问，命中率87.5%。改变访问顺序可能比单纯扩大缓存更直接改善局部性；要从实际循环顺序列地址，不能看见“二维数组”就固定选某个百分比。

7. TLB、页表、Cache：先翻译，再分字段

虚拟页号VPN经TLB或页表查到物理页号PPN，页内偏移不变。页表项有效表示该页当前有合法驻留映射；保护检查、修改位等另按题设。TLB缺失不等于缺页：页表可能已有有效映射，只需填TLB。缺页也不直接归结为Cache缺失，它会引发异常与系统处理。

例9：32位虚拟地址、24位物理地址、4 KiB页。页内偏移12位，VPN20位、PPN12位。虚拟地址0x00012034，VPN=0x12、偏移0x034；页表给PPN=0x35，物理地址就是0x035034。某物理直接映射Cache有64行、64 B块，其偏移6位、组号6位、Tag12位；该地址组号0、Tag0x35、块内偏移0x34。

本例Cache索引和偏移合计12位恰在页内，但这不证明所有机器都可直接用虚拟地址访问物理Cache；是否并行查TLB与Cache、如何做物理Tag核对，需看具体设计。

页表容量从“多少虚拟页”开始

例10：32位虚拟空间、4 KiB页、单级页表，每项4 B。虚拟页共，页表4 MiB。若采用每张表4 KiB的两级页表，一张表放1024项，用10位索引，因此虚拟地址拆10/10/12位。只用了少量虚拟区间时，两级表可按需分配二级页表；不能无条件宣称两级表比单级节约固定倍数。

给出一个能检查口径的平均时间模型

例11：TLB 2 ns，命中率90%；单级页表查找固定额外100 ns；无缺页；数据Cache命中率95%，查询1 ns，缺失在查询后额外100 ns。全部串行，无重叠。

翻译平均时间 ns；数据平均时间 ns；总计18 ns。这里页表访问明确走独立100 ns路径，没有再对其套数据Cache命中率。若题目规定页表本身经过Cache，或两级访存，或TLB与Cache并行，必须重画路径，不能把18 ns当成通用答案。

从Cache性能到CPU时间

基础CPI=1.2，每指令平均1.3次存储访问，其中含取指；统一缺失率2%，每次额外50周期，不重叠。缺失停顿CPI为1.3×0.02×50=1.3，总CPI=2.5。缺失率降到1%时总CPI=1.85；同指令数、同主频下加速比2.5/1.85≈1.351。别漏取指，也别把每条指令的额外周期再乘一次CPI。

专题3：控制信号与时序

1. 时钟不是“每条指令一个周期”的同义词

时钟周期是相邻时钟边沿之间的时间；指令周期是完成一条指令所需的全部过程。单周期设计每条指令一个较长周期，多周期设计每条指令若干短周期，流水设计让多条指令的阶段重叠。不同教材对“机器周期”的具体划分依实现而定，不能强行等同于任何固定倍数。

例1：一台单周期CPU的完整最长路径是取指200 ps、寄存器读100 ps、ALU150 ps、数据存储器250 ps、写回设置50 ps，其他选择器延迟已计入。时钟至少750 ps。即使加法用不到数据存储器，仍按750 ps完成一条，因为这是统一单周期设计。

若改成五段，恰按上述五段划分，各流水寄存器开销20 ps，则周期至少max(200,100,150,250,50)+20=270 ps。无冒险执行100条，需104周期，即28080 ps；原单周期75000 ps，加速约2.671。单条从IF开始到WB结束却要5×270=1350 ps，比原750 ps更长。吞吐改善与单条延迟要分开回答。

2. 指令语义决定哪些部件必须工作

先把指令改写成赋值式，再标出来源、组合运算、目的地。以一种简化MIPS风格单周期数据通路为例：双读单写寄存器堆，指令/数据存储器分开，ALU输入B可选寄存器或符号扩展立即数，写回可选ALU结果或存储器读出。

指令语义 ALU输入B ALU动作 数据存储器 写寄存器？ 写回来源
add rd,rs,rt rt内容 加 不访问 是，rd ALU
lw rt,imm(rs) 扩展imm 基址加偏移 读 是，rt 存储器
sw rt,imm(rs) 扩展imm 基址加偏移 写入rt内容 否 无关
beq rs,rt,label rt内容 减/比较 不访问 否 无关

例2：sw r2,12(r1)。若r1=0x1000、r2=0xAABBCCDD，有效地址0x100C；ALU加r1与扩展立即数12，存储器写数据来自r2，不能把立即数12写进去。寄存器写使能为0，数据存储器写使能为1。低地址字节内容还取决于大小端；小端0x100C处为DD。

控制表中的“无关”表示该输出对本条指令的正确行为不起作用，并非某根线永远不存在。比如sw不写寄存器，写回选择信号可以为无关值；但写寄存器使能不能随便取1。

为什么需要MUX？同一个目的部件在不同指令中可能接不同来源，MUX选择来源；控制信号决定选哪条路。新指令要求的来源、运算、目的地若已有，就可能只补控制；若缺运算部件、输入通路或端口，就必须改数据通路。先追踪语义，别先猜“只加一个控制位”。

3. 单总线微操作：按资源而非按语句数排拍

例3：内部单总线，寄存器输出均需总线；ALU输入之一来自Y，另一个来自总线，结果锁存Z。Z下一拍才能驱动总线；同拍只允许一个总线驱动源，允许多个目的寄存器锁存。求R1←R1+R2的执行段，不含取指。

拍 总线来源 同拍控制与动作
T1 R1 R1out、Yin：Y←R1
T2 R2 R2out、Add、Zin：Z←Y+R2
T3 Z Zout、R1in：R1←Z

不能T1同时R1out与R2out，因为两个源争用总线；也不能在本模型T2让新Z立即经总线写R1，因为该拍总线已有R2且Z需等边沿锁存。

若改成双读端口寄存器堆直接连ALU，再有独立结果通路，同一操作可能一拍完成；答案改变源于结构改变，不是原来的三拍排错。

取指过程同样拆解：PC→MAR，发读请求并等待存储器完成，读出→MDR→IR；PC更新按专用加法器或共享ALU安排。读等待可能多拍，是否能与PC更新并行取决于资源和握手条件。题目没给存储器固定一拍，不能自行假设一拍返回。

4. 微程序题：兼容操作分开编码，后继地址另算

微指令控制一组微操作；若干微指令形成微程序，解释机器指令。控存保存微程序，主存保存机器程序与数据；微地址寄存器和PC作用不同。硬布线控制通过逻辑产生控制信号，微程序控制通过控存读出微指令，再产生控制信号。

例4：三个互斥微命令组分别有7、5、3个命令，每组都要保留“不发命令”。采用字段直接编码，各组可并行。所需位数为ceil(log2(7+1))+ceil(log2(5+1))+ceil(log2(3+1))=3+3+2=8位。若直接控制每条命令各1位，则为15位，但硬件需防止同组非法组合。

控存256字，每微指令还有8位下地址和2位条件选择，则总字长18位，容量256×18=4608 bit。微指令字长不能只回答8位，因为顺序控制字段也占空间。题目给的是映射法、增量法或别的后继地址机制时，按实际字段计数。

分组前必须验证互斥：PCout与R1out在单总线上互斥，PCout与MARin通常可以相容。把一对必须同拍动作放在同一个单选字段，会导致所需动作无法编码。

去掉转发，答案怎样变

例6：同一指令串，无转发，同周期先写后读仍允许。 I2必须等到I1周期5的WB，才能在ID读r1，周期6进入EX、周期8 WB。I3只能在I2周期8写回后完成ID，周期9进入EX、周期11 WB。总11周期，共4个停顿。不能见到两个RAW关系就固定加两拍；每个RAW要等待的时间取决于数据可见时刻。

store有两种不同的“使用时刻”

lw r1,0(r2); sw r1,0(r3)中r1是写入的数据；若有MEM/WB到store的MEM数据端转发，第二条可到MEM时再取得数据，可能无需load-use停顿。若第二条改成sw r4,0(r1)，r1用于EX算地址，通常仍需一拍。是否有这条转发通路必须看图；不能把“load后面用了同一寄存器”一律判成相同停顿。

6. 分支：处罚由决策阶段和策略共同决定

例7：五段流水，预测不跳，分支在EX末判定，正确目标下一周期可取，目标计算不增加周期，无延迟槽。分支在周期3做EX时，后两条错误路径指令分别在ID和IF；若实际跳转，需要冲刷2条，处罚2周期。若判定移到ID末且数据可及时获得，通常只冲刷IF的一条；若比较所需操作数未到，还可能额外等待。

例8：长程序基础CPI=1，20%为条件分支，预测错误率10%，每次错误额外2周期，其他无停顿。分支额外CPI=0.2×0.1×2=0.04，总1.04。“错误率10%”以分支为分母，必须先乘20%；若题给的是所有指令中2%产生预测错误，则不能再乘一次分支比例。短程序还要考虑流水充排，不直接用长程序近似。

结构冒险是资源同拍冲突，数据冒险是值还没准备好，控制冒险是正确后继尚未确定。解决办法要针对原因：加端口不能自动解决未生成的数据，转发也不能让一条尚未完成的load提前产生结果。

7. 总线：把事务拆成时间段

例9：64位总线，100 MHz，每周期传一次数据；一次事务先用2周期发地址与命令，再连续传8个数据拍，无其他等待。峰值带宽8 B×100 MHz=800 MB/s；每事务64 B，用10周期=100 ns，有效带宽640 MB/s。这里MB取 B，若要MiB/s再除。若题给DDR双沿传输，不能在已标为“每秒传输次数”的数字上再乘2。

突发传输减少的是重复事务开销，不改变单个数据拍的宽度。总线仲裁决定谁获得使用权，握手决定一次传输何时有效；集中仲裁的链式、计数器、独立请求等方式要结合硬件开销、固定/轮转优先级及故障影响辨认。异步总线没有统一固定时钟，不等于没有任何时序要求。

8. 查询、中断和DMA：CPU占用到底在数什么

查询方式由CPU反复检查状态；中断使CPU在设备请求时进入处理；DMA由控制器完成一批数据搬运，CPU仍需设置和处理完成事件。接口的数据、状态、控制寄存器分工不同：读到“就绪”状态不代表已经读走数据。

例10：设备稳定1 MB/s，每4 B触发一次中断，每次含进出处理共100周期，CPU100 MHz。中断频率250000次/s，开销25000000周期/s，占25%。若一次中断实际搬16 B、仍100周期，则占6.25%；字节率未变，但事件频率变了。

例11：同设备改DMA，每块4 KiB，CPU设置200周期、完成中断300周期。每秒块数，CPU每秒花周期，占CPU约0.12207%。这是批量搬运相关的CPU控制开销，没有把DMA总线争用导致的CPU等待混入。若题目问总执行时间，还应按访存冲突和传输时序计入等待。

连续一秒的整数块数可能有末尾不满块的问题，本例按长期平均速率计算；题目问一次固定大小传输时，用完整块数及尾块的具体处理。

“不会丢数据”的题要比较服务间隔与缓冲深度

例12：设备每20 μs产生一个字，接口只有一个字缓冲，无设备反压。必须在下一个字覆盖前读走。若最坏请求响应延迟12 μs，进入后3 μs完成该字读出，共15 μs，能满足单次期限；若延迟18 μs、读出还需3 μs，共21 μs，就可能丢字。实际系统还要确保后续持续服务速率足够；一次响应及时不能证明长期不会积压。FIFO深度大于1时应按累积到达量和消费量分析。

9. 中断嵌套：响应顺序和屏蔽规则是两件事

硬件响应优先级决定同时待决时先响应谁；屏蔽与允许嵌套的规则决定处理某中断期间谁能打断它。外部中断请求通常在体系结构允许的边界响应；关中断不等于CPU完全不会遇到同步异常。保存哪些状态由硬件完成、哪些寄存器由软件保存，按题设判断。

例13：A、B、C同时请求，硬件响应顺序A>B>C；服务期间开放中断，屏蔽向量按下表规定，1表示屏蔽，0表示允许。

当前处理 屏蔽A 屏蔽B 屏蔽C
A 1 0 1
B 1 1 1
C 0 0 1

最初先响应A；A开放嵌套后，待决B未被屏蔽，B可打断A；B期间屏蔽全部，完成后回到A；A结束才处理仍待决的C。于是进入顺序A→B→C，完成顺序B→A→C。这里B能打断A并不与初始硬件先选A矛盾，因为两阶段选择条件不同。若题设禁止较低硬件优先级嵌套，则需同时满足该额外条件，不能仅凭屏蔽位判定。

不要混用“1表示允许”的另一种表约定。先在草稿最上面写明1的含义，再逐层保存和恢复屏蔽状态。

专题4：性能与指令综合

1. 性能比较不能只挑一个更大的数字

完成同一任务的执行时间。比较时先问任务是否相同，再确认指令数、CPI、频率是否同时变化。

例1：方案A执行10亿条，CPI=1.5，2 GHz；方案B执行8亿条，CPI=2，2.5 GHz。 A为0.75 s，B为0.64 s，所以B更快，加速比0.75/0.64=1.171875。B的CPI更高不妨碍它执行更快；也不能只因B主频高25%就说快25%。

若一条旧指令替换成两条新指令，必须重新统计N与各类比例。CPI加权的权重是指令数比例，不是原来消耗时间比例。对局部优化则相反，Amdahl公式中的比例是原执行时间比例。

例2：原CPI=2，其中访存停顿占总时间40%；优化只让停顿减半。新总时间占原时间，加速1.25；同N、同f时新CPI=1.6。若题说“访存指令占40%”，却未给其周期贡献，就不能直接套此比例。

用临界条件判断优化是否值得

例3：新编译器把指令数降到原来的80%，但CPI上升到原来的k倍，主频不变。时间比为0.8k；更快要求k<1.25，k=1.25恰相同，超过则更慢。这比代入几组数据猜趋势更可靠。允许写不等式时，先求临界条件再解释。

2. 取指、数据访问、地址运算是不同计数

例4：机器指令定长4 B、按字节编址；指令为ADD R1,[addr]，语义R1←R1+M[addr]，地址已直接编码在指令中，内存操作数4 B，不考虑Cache。完成它需要取指，以及读取数据操作数两个逻辑存储访问；若地址字段改成存储器间接，先从M[addr]读出有效地址，再访问操作数，会增加一次逻辑存储访问。

实际总线事务数还取决于总线宽度、对齐、指令是否跨块及是否命中Cache。因此答“几次访存”前，应确认题目是在数逻辑存储操作、主存访问，还是总线拍数。主存中心结构不意味着所有机器都必须用同一存储端口串行完成取指和读数据。

3. 指令格式：地址空间、寄存器数和操作种类分别占位

例5：32位定长指令，64个寄存器，三寄存器格式有独立8位操作码，余下为保留位。每个寄存器字段6位，共18位；保留32-8-18=6位。操作码最多区分256种编码，不是种操作；三个寄存器字段描述同一条指令的操作数选择，不额外增加操作种类。

若改成双寄存器加立即数、仍8位操作码，则立即数字段12位。有符号补码范围-2048至2047，无符号范围0至4095。字段本身没有天然符号，要由该指令的解释规则确定。

扩展操作码的前缀不能重叠

例6：16位定长指令，每个地址字段4位。已有8种三地址指令，还要安排二地址与一地址指令。三地址指令剩4位作操作码，共16个短前缀，已用8个，尚余8个前缀可扩展。

若安排100种二地址指令，每种用8位操作码和8位地址，则剩余二地址层编码有8×16-100=28个。每个剩余8位前缀还能扩成16种12位操作码的一地址指令，所以一地址最多28×16=448种。

关键不是每层分别算，而是先扣掉被短操作码占用的整棵子树。已经被三地址指令占用的4位前缀，不能再给某条二地址指令使用，否则译码无法唯一判断字段边界。若还有零地址指令，继续从尚未使用的一地址层前缀向下扩。

4. 相对寻址：符号扩展在缩放之前

例7：一种MIPS风格分支，指令地址P=0x1000，定长4 B，16位补码位移字段0xFFFC，以PC+4为基准，位移单位为4 B。字段解释为-4，缩放为-16 B；目标=0x1004-0x10=0x0FF4。

反算目标0x0FF4需要的字段：先算(目标-(P+4))/4=-4，再编码为0xFFFC。差值须能被4整除，商须落在16位补码范围；否则该格式无法直接表达。

如果改成以当前指令地址P为基准，答案会变；如果位移单位改为字节，也会变。不能只背“PC加偏移”而漏掉基准PC究竟是哪一个值。按字节编址时，此格式目标相对PC+4的范围为-131072至131068 B，正负上界不对称。

基址与变址谁负责变化

访问数组通常保留数组基址，让下标换算成偏移；重定位通常让基址变化、指令中的相对偏移保持不变。这是用途上的理解。实际寻址式例如EA=(Rb)+(Ri)×scale+disp，要逐项代值；括号表示寄存器内容而非寄存器编号。

5. 用一个数组地址把端序和Cache连接起来

例8：int为4 B，二维数组a[3][5]按行优先连续存储，首地址0x1000。 a[2][3]之前有2×5+3=13个元素，地址0x1000+13×4=0x1034。把5写成3，是把“每行元素数”错当成“行数”。

若该元素值为0x11223344，小端机器地址0x1034至0x1037依次是44、33、22、11。块大小16 B时，它位于块首0x1030的块内偏移4；若页大小4 KiB，它在虚拟页1、页内偏移0x034。物理块号需在地址翻译后确定，不能跳过页表直接把虚拟页号当物理页号。

若只读取首字节再做零扩展，得到0x44；若读整个int，仍得到0x11223344。端序改变多字节值在连续地址中的排列，不会把一个完整整数自动倒成另一个真值。

6. 调用与栈：先定义SP，再画每次变化

例9：一种调用约定：栈向低地址增长，SP指向当前栈顶；压入32位值先SP减4再写；弹出先读再SP加4。初始SP=0x2000，依次压返回地址0x1040和旧FP=0x3000，随后把FP设为当前SP，再预留16 B局部空间。

压返回地址 0x1FFC M[0x1FFC]←0x1040
压旧FP 0x1FF8 M[0x1FF8]←0x3000

专题5：异常与并行

1. 异常分类要落实到“返回哪条指令”

异常通常由当前指令执行触发，是同步事件；外部中断由设备等外部事件引起，通常在允许的指令边界响应。同步与异步描述事件和指令的关系，不是处理速度的快慢。

类别 判断重点 常见例子 处理后的典型去向
故障Fault 指令未能正常完成，需要处理原因 缺页 可恢复时重新执行故障指令
陷阱Trap 指令有意引发控制转移，或按规则执行后触发 系统调用、调试事件 通常从后续指令继续
终止Abort 严重问题，通常无法恢复正常指令流 严重硬件故障 通常终止程序或进入故障处理

具体异常的分类依ISA与机制确定。例如“溢出”是否触发异常由指令规定，并非所有ALU的OF=1都自动进入同一种处理流程。不能只靠事件中文名称猜保存的PC。

例1：load指令地址0x1000，下一条0x1004；访问合法虚拟页但页不驻留。引发缺页故障；系统装页并修复映射后，要重新执行0x1000的load，才能把数据写进目的寄存器。若直接返回0x1004，就跳过了原程序必需的读取。

变式：若0x1000是按该ISA规定正常完成的系统调用指令，返回位置通常是后续指令，不能为了“继续原程序”就机械重复系统调用。返回地址如何保存、是当前PC还是经修正PC，以ISA规定为准。

屏蔽普通外部中断不消除缺页、非法指令等同步异常。不可屏蔽中断也不由普通可屏蔽中断的开关控制。题目问“关中断后还能不能被打断”，必须辨别所指事件类型。

2. SIMD与MIMD：数的是指令流、数据流

SISD是一条指令流处理一条数据流，经典单处理器可用它描述。采用流水线也不自动变成MIMD，因为重叠执行多条指令不等于多个独立控制的指令流。

SIMD以同一条指令控制多个数据元素执行相同操作，适合规则的数据并行。MIMD有多个独立指令流处理多个数据流，适合任务或线程并行。MISD表示多指令流处理单数据流，实际应用较少。

例2：向量加法一次对8对元素相加。同一指令作用在8组数据上，属于SIMD；8个核各运行独立程序分别处理任务，则按MIMD理解。SIMD的处理单元可以处理不同数据，不要求输入值相同；MIMD的多个核也可以碰巧运行同一程序，不能仅凭程序文件相同就判成SIMD。

3. 三种硬件多线程，别与多核混淆
机制 线程切换/发射特点 主要解决的问题
细粒度多线程 通常每周期在可运行线程间轮换 隐藏单线程等待，提高利用率
粗粒度多线程 遇较长停顿才切线程 用其他线程覆盖长延迟，切换可能有流水代价
同时多线程SMT 同一周期可发射不同线程的多条指令 利用多发射CPU未被单线程占满的资源

硬件为各线程保存独立的体系结构状态，例如PC和通用寄存器；执行部件与部分缓存可共享。SMT增加逻辑执行上下文，不等于复制出完整独立物理核。多核则在芯片内包含多个处理核心。

例3：某单核每周期最多发射2条。线程A和B各有互不依赖的6条指令，但每线程每周期最多提供1条。简化到只计发射周期、忽略其他延迟：细粒度轮换且同周期只发一个线程，12条至少12周期；若SMT允许每周期A、B各发1条，则可6周期发完。若两个线程争用同一唯一执行部件，或存在依赖，6周期就无法保证。

不能用“SMT有两个逻辑处理器”直接推断单线程加速2倍。单线程未必能使用另一个线程的上下文，两个线程还可能争用缓存与执行单元。

4. 共享地址空间不等于所有访问一样快

共享内存多处理器可通过普通访存访问统一的物理地址空间。UMA各处理器访问主存的延迟大致一致；NUMA的延迟与处理器及目标内存的位置有关，通常本地比远端快。NUMA仍可共享统一地址空间，不因为有远端内存就自动变成分布式独立地址空间。

各进程仍可有不同虚拟地址映射，物理共享不意味着每个进程使用完全相同的虚拟地址。多核也不保证共享所有级别Cache，按题图认清私有与共享层次。

一致性与互斥解决不同问题

例4：共享变量x初值0，两核都执行一次x=x+1。若二者先后都读到0，再分别写1，最终x可能是1。即使各核缓存对这同一地址保持一致，也不能把“读—加—写”三个动作自动变成不可分割的整体。需要原子读改写或恰当同步保护，才可保证两次更新都保留。

缓存一致性处理同一地址多个缓存副本的协调；同步还要求并发操作满足程序规定。

5. 核数题必须先算串行上限

例5：任务原时间100 s，20%必须串行，80%可理想并行，无额外开销。 4核时间20+80/4=40 s，加速2.5倍；8核30 s，加速约3.333倍；无限核仍需20 s，最大加速5倍。若4核有额外同步10 s，则为50 s、加速2倍；开销不能被漏进“理想并行”部分。

判断题：单核SMT是否等于双核？否；流水线是否必然属于MIMD？否；NUMA是否不存在统一地址空间？否；缓存一致是否保证x++原子？否；故障返回是否一律下一条？否。

专题6：C类型与边界

char为8位、short为16位、int为32位，整数采用补码；float为binary32，double为binary64，浮点采用最近偶数舍入。其他类型的位宽另行给定。

1. 每个表达式按四步判断

先标出操作数类型 → 做整数提升 → 做该运算要求的类型转换 → 求值后再做赋值转换。变量位宽、表达式位宽、目标变量位宽可能不同。

整数提升：char、short等较低秩整数，若int能表示其全部值则提升为int，否则提升为unsigned int。上述默认条件下，unsigned short也提升为int，因为0—65535都在32位int内。不是看到unsigned就始终做无符号运算。

整数通常算术转换：同符号选择较高秩类型；异符号时，若无符号类型秩不低于有符号类型，转成该无符号类型；否则若较高秩的有符号类型能表示另一类型的全部值，转成它；再否则转成该有符号类型对应的无符号类型。秩与表示范围都要查，不能概括成“有unsigned就全部unsigned”。

移位运算分别提升左右操作数，结果类型取提升后的左操作数类型，不按加法的通常算术转换统一两边。

例1：unsigned short的减法

a、b均先提升为int，表达式为32位int的1-2，结果r=-1。若改成unsigned short r=a-b;，先产生int的-1，再转换到16位unsigned short，结果65535。两者中间表达式相同，差别发生在赋值阶段。

例2：相同宽度的有无符号比较

比较前a转换为unsigned int，得到4294967295，因此r=0。比较并不先按有符号得到真，再把布尔结果转成无符号。

变式：若a为64位long long而b仍32位unsigned int，long long可表示b全部值，则比较转成long long，-1<1为真。必须写出平台宽度与范围。

例3：先运算再存储

x先提升为int，相加得到260；y赋值转为8位无符号数，得260 mod256=4；z保留260。这里没有int加法溢出。若题问ALU当时的OF，也不能拿最终8位y的截断结果倒推32位加法溢出。

例4：强制转换放哪里很重要

令int x=16777217：double d=x;可精确得16777217；double d=(float)x;先舍入成binary32的16777216，再转double，丢失的1不会恢复。

double d=5/2;先做int除法，d为2.0；double d=(double)5/2;先把5转double，再做浮点除法，得2.5。目标变量为double不会倒过来改变右侧已经发生的整数运算。

2. 不能把所有转换和运算都按“截低位”回答

转无符号整数按模归约；转到能表示原值的整数类型，值保持不变；对超出目标范围的有符号整数转换，在C11语义下结果由实现规定或产生实现规定的信号，不能宣称C标准保证任意平台都截低位。计组题若明确给定截断补码机器模型，则在该模型下算，并标明前提。

普通有符号整数加减乘溢出不由C语言保证回绕；无符号运算则按模处理。求出固定宽度ALU位型，与断言任意C源程序必然得到该值，是不同问题。

浮点转整数丢弃小数部分、向零截断；若截断后的值超出目标整数范围，不能继续套普通整数模转换给出通用C结果。NaN或无穷转换也不按一般有限数处理。

选择题速查： int→double在上述位宽条件下精确；int→float可能丢精度；float→double有限值可精确表示；double→float可能舍入或超范围；float→int可能丢小数或超范围。不要把“不超范围”与“不丢精度”混成一件事。

3. 不恢复余数法：把剩余缺口补成完整表

这是无符号整数的一个明确算法模型。商寄存器Q宽4位、余数R用足够的有符号位宽（本例5位），除数D=3。初始R=0、Q=1101。每轮记录旧R符号，把Q最高位带入R：旧R非负则；旧R负则。Q左移，按新R非负置商位1，否则置0。末尾若R<0再加D恢复。

轮 旧R 带入位 更新R 本轮商位 Q更新后
1 0 1 2×0+1-3=-2 0 1010
2 -2 1 2×(-2)+1+3=0 1 0101
3 0 0 2×0+0-3=-3 0 1010
4 -3 1 2×(-3)+1+3=-2 0 0100

最后余数-2需要加3，得1；商4。验证13=3×4+1。中间负余数是算法状态，不能直接当成无符号最终余数。恢复法与不恢复法每轮状态不必一样，但最终商余应一致。算法指定与寄存器宽度确定后再列位型；不要混用“先移后试商”和另一教材的步骤次序。

4. binary32边界不是只记三个极值
例5：正常区间的精确半间隔

1.0编码0x3F800000，紧邻下一个binary32数为。精确值恰在二者中间，最近偶数舍入为1.0，因为保留有效数最低位0。精确值位于随后两个数之间，舍入到，编码0x3F800002。题目若换舍入模式，两个答案都可能改变。

例6：逐步舍入改变运算顺序结果

设a=、b=1.0、c=-，每次运算立即舍入到binary32：先算(a+b)时中点舍入回a，所以(a+b)+c=0；先算a+c得0，所以(a+c)+b=1。浮点加法通常不满足结合律。各步均按binary32舍入，不采用扩展精度中间结果或运算重排。

例7：最小边界的两种情况

最小正规格化数编码0x00800000，减去一个最小非规格化数，得到最大非规格化数，编码0x007FFFFF。数值连续衔接，不是阶码字段变0就一律变0。

精确正值在0与中间，最近偶数舍入为+0；在一个与两个最小间隔之间，舍入到。是否设置具体IEEE异常状态位，还需看精确性、微小性判定和实现条件；此处先回答最终数值，别将下溢与最终非规格化结果简单画等号。

最大有限数加法若先使有效数进位并增加阶码，可能越界；就近舍入时可得到无穷，朝零等模式下可能保留最大有限数，须先读舍入模式。无穷、NaN、正负零优先分类，再使用普通有限数公式。

专题7：虚拟存储与外存

1. 段式：基址加偏移前先检查界限

段按程序的逻辑部分划分，长度可变。逻辑地址由段号和段内偏移组成；段表记录基址、长度以及有效和保护信息。段号决定查哪项，偏移决定段内位置。段式可有外部碎片；固定页框的页式避免这种外部碎片，但末页可能有内部碎片。

例1：段2基址0x8000，段长0x300 B，段内偏移0x2FC，要读4 B。有效偏移为0至0x2FF；此次访问末偏移0x2FC+4-1=0x2FF，合法；物理起址0x82FC。若偏移为0x2FE，同样读4 B，末偏移0x301越界，不能只检查起点小于段长就放行。段号越界、段不驻留与读写权限不符也是不同检查。

若题目给段界限为“最大合法偏移”而非“长度”，比较式会改变：长度L时末偏移<L，最大偏移Limit时末偏移≤Limit。读定义后再判断等号。

2. 段页式：先段表、再该段页表、最后拼地址

一个段内部再分页。段表给该段页表位置和界限，段内页号查对应页表，页表给物理页框号。页内偏移保持不变；段号不能直接当物理页框号。

例2：页大小1 KiB；段2的页表起址0x2000，页表项4 B；查逻辑地址(2,3,0x34)，第3号页表项给PPN=0x12，均合法且驻留。页表项地址0x2000+3×4=0x200C；物理地址0x12×0x400+0x34=0x4834。段表项地址则由段表基址与段表项大小另算，不能把0x2000误当段2的数据基址。

无TLB、所有表均在主存且不经Cache的模型下，取得一个数据需读段表项、读页表项、读数据，共3次。表项缓存、TLB或跨页访问会改变次数。与两级页表区别在于：段页式先按逻辑段选页表，两级页表则将一个虚拟页号拆成多级索引；不要因二者都“查两张表”就说结构相同。

3. 页替换、Cache与TLB的状态分开

页表驻留位回答页是否在主存；TLB缓存部分页映射；Cache缓存数据或指令块。缺TLB可以只查页表，不必访问磁盘。缺页处理后通常重试原指令，因此同一逻辑访问可能出现多次TLB查询，按题目是否计重试决定。

例3：页大小4 KiB，主存只给本进程3个页框，初始空，页访问串0,1,2,0,3,1，LRU。前3次缺页装0、1、2；第4次0命中，最久未用变为1；第5次3缺页换1；第6次1缺页换2。共5次缺页。这里替换的是页，不能拿Cache行数约束它，也不能把页内每条指令算作一次缺页。

若页0可写且已修改，换出它可能需要回写外存；干净只读页可能不需回写。页表/TLB对应映射也必须一致更新；

5. 磁盘完整计算：容量、速率和时间要互相一致

例5：8个有效记录面，每面4096磁道，每道512扇区，每扇区512 B；7200 rpm，平均寻道5 ms。忽略控制器、跨道切换和排队开销。

容量=8×4096×512×512 B= B=8 GiB。每道有效数据256 KiB，每秒120圈，因此理想顺序数据率30 MiB/s。读64 KiB连续数据的传输时间为64 KiB/30 MiB/s=2.0833 ms；平均旋转等待为半圈，即4.1667 ms；平均访问时间5+4.1667+2.0833=11.25 ms。

这里一次请求仅加一次平均寻道与旋转等待，因为题设连续读且忽略额外切换。若64 KiB分散在许多随机扇区，需要逐请求计定位开销；若已经给定目标扇区的角位置与当前转角，就按实际旋转时间，不再加“平均半圈”。

柱面是各记录面上同一半径的磁道集合；磁头/盘面号选择记录面。盘片数不等于有效盘面数，题目明确有效面时直接使用。地址位数先算柱面、磁头、扇区各字段可表示的种类数，不能把每扇区字节数又塞进只标识扇区的地址字段。

磁盘阵列只抓基本能力

N块等大盘、每盘容量C：RAID0条带化，无冗余，容量NC，不能容忍任意一盘丢失；RAID1镜像，成对镜像的常见模型有效容量约NC/2；RAID5分布式奇偶校验，通常需至少3盘，有效容量(N-1)C，可在一盘失效时恢复数据。具体故障组合和其他级别按题设。冗余提高可用性，不等于替代所有备份需求。

6. SSD：页读写、块擦除与写放大

SSD没有磁头寻道和盘片旋转，不能套磁盘定位公式。闪存通常以页读写，以更大的擦除块擦除；覆盖旧数据往往写到新位置，由闪存转换层维护逻辑到物理映射，旧页标失效，垃圾回收再迁移有效页并擦块。磨损均衡尽量分散擦写负担，不是让每个逻辑写入都必须同时改写全部块。

例6：一个8页擦除块中6页仍有效、2页失效。为回收该块，需迁移6个有效页到已擦除空间，再擦除旧块；另有2页主机新写入。若只统计这次回收加新写形成的页编程量，内部写6+2=8页，主机写2页，写放大=8/2=4。擦除次数另计1次，不能把“擦一个8页块”又作为8次页编程加入分子。

页4 KiB、块256页时，擦除粒度1 MiB。改4 KiB并不必然立即擦除原1 MiB块；是否迁移、何时回收由控制器和空闲空间状态决定。题目若给了固定迁移流程，就按它算，不用固定“每次写放大256倍”代替分析。

1. 读汇编先解决四个基础问题

Intel双操作数通常是“目的,源”；[地址表达式]表示内存内容，没有方括号的寄存器表示寄存器值；byte/word/dword分别8/16/32位，x86的word不是“当前CPU字长”；目的变量与数据来源的位宽都要看清。

指令 最小语义 常错点
mov eax,ebx EAX←EBX 方向别反
mov eax,[ebx] 读EBX指向的4 B EBX是地址，EAX是取出的内容

普通mov通常不允许两个显式操作数同时是内存。要实现M[A]←M[B]，一般先读到寄存器再写回。

AT&T例movl 8(%ebx,%ecx,4),%eax对应Intel mov eax,[ebx+ecx*4+8]。AT&T通常源在前、目的在后，立即数有$前缀，寄存器有%前缀；这些是表示格式差别，不是CPU执行方向改变。

例1：地址与内容连续追踪

EBX=0x1000、ECX=3，地址0x1014的4字节为78、56、34、12。lea eax,[ebx+ecx*4+8]得到0x1014；随后mov edx,[eax]得到0x12345678。若把lea误作load，第一条就错，后续再把0x12345678当指针会连锁出错。

2. 分支表要区分有符号与无符号

以下均以刚执行cmp A,B即A-B为前提。

含义 有符号跳转 标志条件 无符号跳转 标志条件
A=B je ZF=1 je ZF=1
A≠B jne ZF=0 jne ZF=0
A<B jl SF≠OF jb CF=1
A≤B jle ZF=1或SF≠OF jbe CF=1或ZF=1

例2：EAX=0xFFFFFFFF、EBX=1。 cmp的32位结果0xFFFFFFFE；CF=0、ZF=0、SF=1、OF=0。jl会跳，因为-1<1；ja也会跳，因为4294967295>1。两条都能成立，是同一位型的两种数值解释，不是处理器自相矛盾。

跟踪分支时找最近一次有效修改相关标志的指令，不一定是最近的cmp。例如cmp后执行add会更新标志，随后jcc用的是add后的标志。mov、lea和not不更新算术标志；inc/dec会更新部分标志但保留CF。不要把“所有算术逻辑指令都改全部标志”当规则。

3. 从if-else还原条件，而不是机械翻译标签
例3：求两个有符号数的较大值

若x≥y跳过赋值，保留x；否则EAX=y。对应return x>=y ? x : y;。关键是jge跳的是“无需改结果”的路径，别把跳转条件直接当成then语句条件而漏看代码布局。若输入声明为unsigned，应使用jae等无符号条件，不只改C注释。

5. 调用题把一张栈图画清楚
例5：32位cdecl式调用，右到左压参数，调用者清理

执行前ESP=0x2000，EBP=0x3000。调用add2(7,9)：先push 9，再push 7，call压入下一条指令地址。进入函数后执行push ebp; mov ebp,esp; sub esp,8。令call的返回地址为RA。

函数可用mov eax,[ebp+8]; add eax,[ebp+12]得到16；leave等价于mov esp,ebp再pop ebp，ESP变0x1FF4、EBP恢复0x3000；ret弹RA，ESP变0x1FF8；调用者add esp,8清参数，回0x2000。

为什么第一个参数不是[EBP+4]？那里是call压入的返回地址。为什么不能始终用ESP+固定偏移取参数？函数中push或临时分配会改变ESP；EBP建帧后通常保持稳定。真实编译器可省略帧指针，也可提前分配参数区；本例规则不是所有ABI的通则。

函数若使用约定要求被调用者保存的寄存器，要入栈保存并在返回前恢复；调用者保存的寄存器则由调用者自行保护仍需保留的值。不能因同名寄存器在调用前后出现，就认定函数必然保留它。

6. 乘除与标志位补充

32位无符号mul可形成EDX:EAX的64位乘积；低32位在EAX。32位div以EDX:EAX作为被除数，商放EAX、余数放EDX。做小的无符号除法前通常需使高半部EDX为0，但若题目本来就给64位被除数，不能擅自清掉它。

有符号idiv需让被除数高半部与低半部形成正确的64位补码；例如用cdq把EAX符号扩展到EDX:EAX。它不是把EDX一律清0。除数0或商超出目标位宽可触发除法错误；“被除数很大”本身不足以判断，必须看除数及商范围。

乱序执行还需维护程序语义；寄存器重命名能缓解假相关WAR/WAW，不能消除真正RAW数据依赖。精确异常要求处理程序能够观察到与顺序执行相符的体系结构状态。

图源：王道PDF物理页297，书内285页。箭头表示一方动作依赖另一方信号：不互锁用预定延迟撤销；半互锁请求方等响应再撤请求，响应方按固定延迟撤响应；全互锁两边撤销都等待对方。别把“有没有公共时钟”和“有没有相互等待”混成一个判断。

例5：四阶段全互锁握手耗时

请求与响应每个信号单程传播10 ns；从设备收到请求后20 ns备好数据并发响应；主设备收到响应立即取数据并撤请求；从设备收到请求撤销立即撤响应；主设备收到响应撤销后可开始下一事务。每事务传4 B，不计额外仲裁。

首次取到数据40 ns，但相邻完整事务最小间隔60 ns。持续带宽4 B/60 ns≈66.67 MB/s；不能按4/40 ns算长期吞吐，因为复位阶段仍占时间。若协议允许流水事务重叠，需要另给规则，不能默认为可重叠。

分离式事务释放的是等待阶段的总线

请求阶段只发地址和命令，之后释放总线；从设备准备好时再争用总线返回响应。请求与响应通常带标识便于配对，不要求准备期间总线一直空闲，也不保证各响应顺序一定与请求顺序一致，按协议规则处理。

例6：单次读请求占10 ns，设备准备80 ns，响应传数10 ns。独占事务从头到尾占100 ns；分离式事务实际占总线20 ns，中间80 ns可用于其他事务。单个请求的最低响应延迟仍为100 ns，

5. 轮询开销：检查次数与设备产出次数未必相等
例7：定时轮询

设备每1 ms产生一个数据，接口只有一个数据缓冲；CPU每100 μs检查一次，一次检查20周期，100 MHz。每秒检查10000次，占200000周期，即CPU的0.2%。若每次真正读取和处理额外80周期，设备稳定每秒1000数据，则再占80000周期，总0.28%。不能把所有10000次检查都算成一次成功传输。

最坏轮询发现延迟接近100 μs，另加处理到读走的时间；这里可在下一1 ms数据到来前处理。若CPU一直忙等而没有用间隙做其他工作，即使每次检查只20周期，等待期间也不能全部算成对应用程序可利用的空闲时间。定时轮询与阻塞忙等是不同调度模型。

6. DMA争用：CPU管理开销、总线占用和实际停顿分别算
例8：每个DMA请求必然与CPU冲突的周期挪用模型

DMA速率10 MB/s，每次传4 B；每次独占主存总线100 ns。每秒有250万次传输，占总线0.25 s，即25%。若本题规定CPU在这些时段每次都需要主存且完全不能推进，CPU因此等待25%的墙钟时间。若CPU可执行寄存器运算、命中私有Cache或这些时段原本不访存，真实停顿可更少；“总线被占25%”本身不能直接推出所有程序慢25%。

题若给CPU任务有不重叠的有效工作时间0.75 s，DMA在整个执行期间稳定占25%且每次均阻塞有效推进，则实际完成时间 s。不能简单做0.75×1.25；等待比例的分母是最终墙钟时间。

例9：CPU与DMA交替访存的可行性

CPU每1 μs只需一次500 ns主存访问，剩余半周期可供DMA；若DMA每字需要500 ns且传4 B，固定交替时DMA峰值4 MB/s。若设备要求6 MB/s，这个固定时隙安排不够，须改变调度或提高带宽，不能说“DMA不执行CPU指令所以不受限制”。

DMA预处理设置起址、计数和方向；传送期间控制器更新地址与计数；块结束可发完成中断。DMA请求申请的是访存/总线使用权，完成中断请求的是CPU进入处理，两者时机与用途不同。

解答区
题1解：先统计总周期，再重新分母

题2解：写出每个阶段的类型

题3解：后级局部率要乘到达该级的概率

题4解：跨页后映射可以不连续

前两个字节VPN0、偏移0xFFE与0xFFF，物理地址0x3FFE、0x3FFF；后两个字节VPN1、偏移0与1，物理地址0x8000、0x8001。清低6位得到Cache块首址0x3FC0、0x8000。

题5解：独立工作填掉load-use间隔

题6解：先给每组预留空操作

**题意：**自定义sub ax,imm语义为(imm)−(ax)，编码2Dxxxx，立即数−3且AX=7，立即数按小端排列。

步骤：−3的16位补码FFFDH，小端两个字节FD FF；整条编码2D FD FF。语义依题设为−3−7=−10，16位可表示，OF=0，选A。

**为什么：**这里是题设自定义语义，不能拿熟悉的x86同名指令覆盖它。字节序只交换字节位置，不能把每个字节内部的位反过来。

16. §4.4 选择01：RISC不靠绝对化断言（第192页）

**题意：**判断RISC是否必用流水线、用了流水线是否必是RISC、是否通常有较多通用寄存器。

**推理：**流水线是实现技术，CISC也可采用；指令集分类不保证某个具体实现一定流水化。“RISC通常有较多通用寄存器”符合教材，选D。RISC格式规则有利于实现，不等于任何程序都更快。

17. §5.2 选择11：中断检查时点（第205页，2011统考）

**题意：**不考虑Cache和预取，CPU处于开中断，判断指令执行描述。

**思考：**区分一条指令的执行过程中访存、时钟周期，以及结束时检查中断。不要把“某个特定指令执行结束才检查”当成通则。教材错误项D；在模型允许响应的指令边界检查外部中断，并非只在程序转移指令结束时检查。

18. §6.2 选择20：非突发总线读块（第288页，2023统考）

**题意：**64位数据总线，1GHz；地址传送1周期；每次64位数据主存准备6ns；不支持突发；块32B。

**步骤：**周期1ns；每次8B，需4次。每次地址1ns+准备6ns+数据1ns，共8ns；整块32ns，选D。

**易错：**若只付一次寻址/准备，就偷偷引入了突发或流水条件。题目专门给“不支持突发”就是约束。

19. §7.3 例7.2：是否能使用单字中断（第300页）

**题意：**CPU500MHz、CPI4；设备40MB/s；缓冲32bit；每次中断至少400周期。

**步骤：**每0.1μs来4B，服务每次至少0.8μs，CPU跟不上。请求率/s，若逐字中断，CPU所需周期/s，高于可用/s，需求占800%，不能持续处理。

**验算：**从单次时间与每秒负荷两条路线得到相同结论。400已是周期，不应再乘CPI。增大缓冲或DMA改变模型后需重新算。

20. 把一道综合题拆成可检查的中间量

这是一道自编变式，不是王道原题。32位物理地址；Cache数据区16KiB，32B块，2路；按字节编址，初始空，LRU。顺序访问字节地址0、32、8192、0、16384、8192，每次只读1B。

**先想地址：**512行、256组；偏移5位、组号8位、Tag19位。块号为0、1、256、0、512、256；组号为0、1、0、0、0、0。

**再模拟状态：**仅写目标组，括号内从最近到最久。

访问 组 结果 该组访问后块号顺序 原因
0 0 缺失 (0) 冷启动
32 1 缺失 (1) 另一组，不能占第0组空行
8192 0 缺失 (256,0) 第0组第二路空闲
0 0 命中 (0,256) 更新LRU
16384 0 缺失 (512,0) 替换最久未用256
8192 0 缺失 (256,512) 替换最久未用0

**最后验算：**共6次，命中1次，命中率1/6；容量虽然远大于3个块，仍会因为映射到同一组而冲突。把2路当“全Cache任意放两行”，会忽略组约束。
