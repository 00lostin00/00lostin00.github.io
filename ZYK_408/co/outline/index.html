计算机组成原理：知识与解题笔记

目录

  2. 数据表示与运算

  4. 指令系统：寻址、编码、C程序与机器执行

  6. 总线与I/O：传输过程及CPU开销

符号与单位：表示整数的总位数，包含符号位；容量先区分bit与Byte；地址若无特殊说明按字节编址。具体题目与这些默认约定不一致时，以题目为准。

一、系统与性能

1. 程序执行过程

预处理处理宏与包含等；编译把高级语言转换到较低层次表示；汇编生成目标机器代码；链接组合目标文件和库、处理符号引用与地址安排。考试题中不要把“汇编”与“链接”互换。

ISA是软硬件接口。它规定软件可见的指令、寄存器、数据类型、寻址与异常等规则。数据通路、控制信号怎样实现这些规则，属于实现层面。相同ISA的机器可以有不同主频、CPI和内部组织。

图源：强化讲义PDF第2页。ISA连接软件与硬件实现层。操作系统属于软件，不能把它与ISA等同。

2. 存储程序与五大部件

计算机系统由硬件和软件组成。经典硬件分类为运算器、控制器、存储器、输入设备、输出设备。CPU通常包含运算、控制和寄存器等部分。

指令和数据都以二进制存储，不能只凭位型区分。CPU根据访问目的、当前阶段以及相应控制方式解释取出的内容。“存储程序”强调把程序也作为存储内容，使机器能连续取出并执行。

选择题切入点：题目问“完整系统”要想到软硬件；问“五大部件”按经典分类；问CPU组成时不要把主存算进CPU。

3. 程序执行时间

是实际执行指令数，是该程序对应的平均每条指令周期数，是主频。

推导思路：执行多少条 × 每条占多少周期 = 总周期；再乘每周期多少秒。知道这个过程，就不容易把主频乘到分子。

指标 问的是什么 容易误用的地方
主频 每秒多少周期 不等于每秒指令数
CPI 每条指令平均多少周期 不同程序可能不同
MIPS 每秒多少百万条指令 不能脱离任务比较不同ISA的性能
FLOPS 每秒多少次浮点运算 浮点运算次数不等于指令数
响应时间 一项任务从提交到完成要多久 不只包含CPU工作时间
吞吐量 单位时间完成多少任务 不等于单项任务响应时间的简单倒数，除非模型允许

4. 题型：加权、比较、优化、局部加速

看到比例表：先求加权CPI。例：三类指令占比50%、30%、20%，CPI分别为1、2、4，则平均CPI为。若主频2 GHz、执行条，则时间0.95 ms。

看到优化比例：直接写时间比。

指令数变成0.8倍、CPI变成1.1倍、主频不变，则时间变成0.88倍。不要把各项改善百分比直接相加。

看到指令替换：只算差值。若旧指令需20周期，新指令需2周期，替换次，主频为，则节省秒。其余指令没有变化时会抵消，不必先求程序总指令数。

看到某一部分提速：保留未改善部分。原时间100 s，CPU占80 s，CPU速度提升至2倍、I/O不变，则新时间 s。

通式为。是可加速部分在原总时间中的比例，是该部分的新速度/旧速度。适用于题目采用各部分时间相加的模型。

落笔顺序：写和单位 → 标出哪些改变 → 算绝对时间或比值 → 用“时间越小越快”检查结论。

二、数据表示与运算

1. 位型与真值

同一个8位位型11111111，按无符号数读是255，按补码整数读是-1。位没有变，解释规则变了。十六进制只是位型的紧凑书写，不自动规定有符号性。

编码，总共位整数 真值范围 读法
无符号 全部按正位权
原码 最高位标符号，其余读绝对值
补码 最高位权，其余正权

原码有正零、负零，补码零唯一。反码负数由对应正数的全位取反得到，也有两个零。移码按“真值+指定偏置”计算；只有偏置为时，才可直接用同宽补码翻转最高位。

例： 8位BEH，，补码真值。反过来求-66的补码，就算，再写成BEH。

2. 进制、扩展、截断

二进制转十六进制按四位分组；转八进制按三位分组。整数端从小数点向左分组，小数端向右分组。不足位只能在外侧补零，不能改变小数点位置。

位宽改变的三条规则：

  • 无符号扩展：高位补0。
  • 补码有符号扩展：高位复制原符号位，保持真值不变。
  • 截断：保留低位；真值是否改变，取决于被截掉的内容和目标解释方式。

做C类型题的表格：

步骤 类型与位宽 位型 当前真值
原变量 先按题设写 写全位型 按原类型解释
转换后 新类型、新宽度 扩展/截断/重新解释 重新求值
参与表达式 先考虑整数提升与通常算术转换 再计算 最后判断比较结果

注意：表达式中的char/short常先提升成int，不能看到8位变量就把整个C表达式当成8位加法。机器指令题则按题设运算宽度计算。对真实C语义，有符号溢出不能普遍解释为自动回绕；考试明确给定位宽、补码及机器指令行为时按该机器模型求解。

标志 核心含义 解题办法
ZF 结果是否全0 检查保留的结果位
SF 结果最高位 只看位型，单独不能证明有符号大小

加法OF：同号相加得异号。减法OF：异号相减，结果符号与被减数不同。也可用最高位进位与最高位出位的异或判断。

8位加法：，位型为A0H；按补码读成-96，OF=1，但无符号和没有超过255，所以CF=0。OF与CF不是同一个问题。

若题设使用x86式CF借位约定，执行后：无符号看CF；有符号看；小于等于还要并上ZF。其他体系若CF定义不同，以题设为准。

4. 移位与ALU

逻辑右移高位补0，算术右移复制符号位。补码算术右移可能损失低位精度，负数结果不应直接套“截去小数部分的除法”。逻辑左移与算术左移的移位动作可相同，但有符号解释下要额外判断溢出。

加法器电路题：每位和位由本位A、B和进位决定；串行进位等待前一级，先行进位通过生成/传递关系缩短等待。若题目要求门延迟，要按给定逻辑级数和门延迟算，不能把“位数”直接当“时间”。MUX从输入中选一路；译码器把输入编码转换为一组选择信号，两者作用不同。

5. 乘除法：先定算法和寄存器含义

无符号乘法可理解为按乘数位决定是否加被乘数，再移位累积；位乘位，完整乘积最多需要位。有符号乘法必须处理符号，可依题设采用补码乘法或先求绝对值再定符号。

逐步执行题用表：“轮次｜部分积/余数｜乘数或商｜本轮操作｜移位后的值”。每轮明确是先加后移、先移后加，以及整体联合移位哪些寄存器。

Booth补码乘法常通过相邻乘数位决定加、减或不操作；规则取决于题设对相邻位顺序的书写，必须对照表使用。除法的恢复余数、不恢复余数算法也不要混表。

结果验算： 。余数符号与商的取整方式按题设；无符号整数除法应满足。除0、商超过目标位宽都要先检查。

反向题步骤：十六进制转位串 → 切1/8/23或1/11/52 → 先看特殊E → 求真实指数 → 恢复有效数 → 加符号。

四个量要能推出： binary32最小正规格化数；最小正非规格化数；最大有限值；规格化数有24位有效二进制精度。

浮点加减流程：对阶 → 有效数加减 → 规格化 → 舍入 → 检查溢出与必要的再规格化。对阶通常小阶向大阶看齐；舍入可能产生进位。阶码位数主要影响范围，尾数位数主要影响精度。

精度题抓临界值： binary32能精确表示内的全部整数，但更大区间并非一个都不能表示；在某些范围中只可表示间隔为2、4等的整数。不要把“超过临界值”写成“一律不精确”。

7. 本章验算清单

先写位宽、符号性、小数点位置 → 写位型 → 做硬件运算 → 分别解释真值、OF、CF → 检查边界。负数补码、最小负数、符号扩展、有符号/无符号比较是需要反复练熟的基础。

三、存储系统

1. 先认清存储层次

寄存器、Cache、主存、外存形成速度与容量的层次。Cache利用时间局部性和空间局部性缓解CPU与主存速度差异；虚拟存储侧重地址空间、保护与按需调页。Cache缺失、TLB缺失、缺页是三种不同事件。

存储介质 关键机制 做题抓手
SRAM 触发器等静态单元，无需像DRAM那样刷新 常用于Cache，速度与成本
DRAM 电容存储，需刷新，行列地址复用 主存、刷新开销、地址引脚
ROM/Flash 非易失性；Flash写入与擦除有约束 不能把“非易失”理解成完全不可写
磁盘 寻道、旋转、传输 各部分时间和容量
SSD 无机械寻道与旋转，基于Flash等 不能照搬磁盘机械延迟公式

芯片写作位，表示个单元，每单元位；地址位数为，数据宽度为。DRAM外部地址引脚可能复用，不能直接等同于逻辑地址位数。

若目标、单片，在规格整除的常见题设下：

例：用位芯片组成位存储器。每组并联4片扩字宽，共4组扩字数，总16片；组内接相同低13位地址，高2位译码选择4组。

地址范围题：先求该组容量对应多少个可编址单位，再算“末地址=首地址+单元数-1”。只有按字节编址时，才能直接把Byte数代入地址差。

3. 交叉编址与存储带宽

低位交叉常把体号放在低位，使连续地址轮流进入不同存储体；高位交叉把连续一段地址放在同一体内。能否提高实际带宽还取决于访问模式、存储周期、总线和启动间隔。

图源：强化讲义PDF第82页。读上图：连续地址变动时，先看体号变不变，再看体内地址。读下图：行地址选择行并送入行缓冲，列地址选择需要的数据；行列复用是引脚与时序机制，不是地址位数凭空减少。

若每体周期、相邻访问启动间隔，要持续每发起一次且不撞回尚未恢复的体，常见条件为。理想顺序读个单位常写成，前提是题设确实允许重叠且无其他瓶颈。

刷新题先找刷新周期、总行数、每行刷新所占时间；分清集中、分散或异步刷新。不能把刷新一次的行数误当成全部存储单元数。

5. Cache访问序列与命中率

建立表：“访问地址｜块号｜组号｜Tag｜命中/缺失｜替换后内容”。先按块归并连续访问，再考虑跨块、冲突、替换和初始状态。

直接映射Cache有4行，访问块序列且初始空：前4次强制缺失，第5次命中，第6次块4替掉行0，第7次块0再缺失，命中率。

LRU更新最近使用次序，命中也会改变次序；FIFO按装入次序，命中通常不改变次序。更新范围是该组，不是整个Cache，除非全相联。

情况 策略 动作
写命中 写直达 更新Cache并向下层写，常结合写缓冲
写命中 写回 更新Cache、置脏，替换脏块时再写下层
写缺失 写分配 先把块调入Cache再写
写缺失 非写分配 不调入该块，直接向下层写

写命中和写缺失策略是两个维度，不能因为看到“写回”就跳过题目对写缺失的规定。

7. 虚拟地址、TLB、页表、Cache串起来

页大小字节时，虚拟地址拆为“虚页号VPN｜页内偏移p位”；页表或TLB把VPN转换成物理页框号PPN，偏移不变。

这是便于解题的串行逻辑模型；有的Cache可与TLB并行索引，有的题给多级页表，以具体结构为准。

三种失效的区别： TLB缺失只说明快表没有翻译；Cache缺失只说明所需数据块不在Cache；缺页说明页面当前不在主存。前两者都不必然访问磁盘。

算访问次数：按“当前路径实际经过几次查找”列树，再乘概率。一级页表、无快表、页面在主存时，若一次读取需要先访存查表再访存取数，就是两次主存访问；多级、缓存和并行会改变计数。

四、指令系统

1. 分清四种长度

机器字长：CPU自然处理数据的宽度；指令字长：一条指令多少位；存储字长：一个存储单元的位数；地址长度：可编码地址的位数。它们可能相同，也可能不同。

定长指令便于对齐取指，不意味着一条指令只做一步；RISC常采用规整格式与load/store组织，但具体指令行为仍以ISA为准。

2. 有效地址EA是解题中间量

用表示指令地址字段，表示寄存器内容，表示地址x处内容：

寻址 从哪取得操作数/地址 先写什么
立即 常量在指令里 操作数=，不再按A访存取数
直接 指令字段给出存储地址 EA=，操作数=
间接 字段所指位置保存EA EA=，再取
寄存器 指令指定寄存器 操作数=
寄存器间接 寄存器保存EA EA=，再取
基址/变址 基准与偏移相加 EA=寄存器内容+扩展后偏移
相对 PC基准与位移相加 先明确是当前PC还是下一条PC

通用步骤：找字段 → 判断存的是数据、地址还是寄存器编号 → 扩展偏移 → 按单位缩放 → 求EA → 按数据宽度取数。

“访存次数”要看题目是否把取指计入，是否通过Cache，以及间接寻址是否多次间接；不能只背“某寻址固定几次”。

3. 分支位移：PC基准和缩放是两个独立条件

在典型32位MIPS、按字节编址、beq类指令的题设下，常用：

若PC=1000H、目标1010H，偏移为。不能把目标地址直接填入16位字段。

这是具体ISA的公式。题目给其他架构或自定义指令时，先找PC基准、位移位宽、符号扩展和缩放规则。不要把“PC+4”推广到所有指令集。

4. 指令格式与扩展操作码

若指令总长、每个地址字段位，有个地址字段，则剩余位可用于操作码和其他控制字段。实际题目若另有寻址模式等字段，还要扣掉。

扩展操作码题：画前缀树，从长地址指令开始分配；某前缀已用于短操作码，就不能同时成为另一个完整操作码的前缀。每剩一个长度的前缀，多扩位就可得到个新编码。逐层扣除已用前缀，不要把不同长度的编码直接相加。

5. 大小端、对齐与数组地址

小端：低有效字节放低地址；大端相反。0x12345678从地址A起存放，小端依次为78 56 34 12。这不改变每个字节内部的位权，也不改变CPU寄存器中的数值。

数组元素地址：

连续行优先二维数组：。结构体成员偏移还受对齐与填充影响，不能只把各字段字节数机械相加。

解题模板：明确下标/循环变量 → 算字节偏移 → 得到地址 → 按端序重组位型 → 按类型解释真值。若变量类型由int换成short，地址步长可能变，但指令是否也要改取决于题设。

6. 调用、栈与返回

调用通常需要记录返回地址；栈保存局部数据、参数或现场，但具体哪些寄存器由调用者/被调用者保存由约定决定。读汇编时跟踪SP、返回地址寄存器和保存位置，别默认所有机器都采用同一栈方向或调用规范。

对递归题，每层栈帧大小乘同时存活层数，而不是乘调用总次数。返回后SP应按约定恢复，可作为验算。

五、CPU与流水线

1. 寄存器的任务先分清

寄存器 本章主要用途 易混点
PC 指示取指地址与控制流位置 与IR不同
IR 保存当前指令、提供译码字段 不是下一条指令地址
MAR 保存访存地址 位数联系可寻址单元数
MDR 暂存访存数据 位数联系数据通路宽度，不等于地址位数
通用寄存器 操作数、结果或地址 同一寄存器内容如何用由指令决定
PSW/标志 状态、条件等 具体内容由ISA规定

取指可抽象为，发读请求，存储内容经数据通路进入IR，并更新PC。是否能同时完成、需几个周期，取决于图和时序条件。

2. 数据通路题：先写语义，再沿图走

例： load的语义是“基址+偏移求EA，读内存，结果写目的寄存器”；store是“求EA，把源寄存器数据写到内存”，没有把结果写回通用寄存器这一步。

图源：强化讲义PDF第135页。MUX选路、加法器相加、ALU按操作控制产生结果。控制信号决定选择和写入，但数据沿数据线传递。

按这个顺序填控制表：

  1. 列出读哪些寄存器、写哪个寄存器、是否访存。
  2. 确定ALU的两个输入和运算。
  3. 确定写回来源是ALU、存储器还是其他来源。
  4. 确定PC顺序前进还是分支/跳转。
  5. 给MUX选路、寄存器写使能、存储器读写、ALU控制赋值。

无关信号才可写X。例如不写通用寄存器时，写回MUX可能无关；但MemWrite若随意写X，可能产生意外存储，不能因为“该指令不访存”就把它当无关。

3. 单总线、多周期：先检查资源冲突

单条内部总线同一时刻通常只能由一个源驱动，多个目的寄存器可在条件允许时同时接收同一个值。ALU要做双操作数运算时，常需要暂存器保存一个输入。

排微操作步骤：写出不可省的操作 → 标依赖 → 检查总线谁输出、谁接收 → 标访存等待 → 再合并能并行的步骤。不能把同一条总线安排成“R1输出A、R2同时输出B”。

4. 控制器：机器指令与微指令不是同一层

硬布线控制通过组合逻辑、状态和时序等产生控制信号；微程序控制从控制存储器读取微指令，逐步给出控制信号和后继地址。微指令位于控制实现层，不是用户程序中的机器指令。

计算题：微指令字长=操作控制字段+判别字段+下址等字段；控存容量=微指令条数×每条位数。水平型可并行控制较多操作，字段编码可缩短字长但增加译码约束。填字段前先判断哪些微操作互斥、哪些可能同周期发生。

5. 流水线：跨指令重叠，不保证单条更快

典型五段为IF取指、ID译码/读寄存器、EX执行、MEM访存、WB写回。不是每条指令都做实际内存读写，也不是每条都有通用寄存器写回。

图源：强化讲义PDF第157页。横向看一条指令经历阶段，竖向看同一周期不同指令争用哪些资源。原图中的无冲突排布是理想示意，遇到相关要重新插入停顿。

图源：强化讲义PDF第159页。注意阶段间的寄存器：它们保存跨周期使用的数据和控制信息。读图要跟踪同一条指令的数据，避免把后一条指令当前的字段误用于前一条指令。

理想段流水线、每周期、连续执行条且无停顿：

周期通常取最慢一级组合延迟加流水寄存器开销。若另有个未重叠停顿周期，则常写。吞吐率为，稳态上限约；与非流水比较的加速比要先写清比较基准。

6. 冒险题：结果什么时候产生，下一条什么时候需要

类别 冲突来源 典型处理
结构冒险 同周期争同一硬件 增加资源或停顿
数据冒险 后指令要用尚未可用的数据 转发、停顿、合法调度
控制冒险 分支结果/目标尚不确定 停顿、预测、冲刷等

RAW题的标准动作：给每条指令列“读寄存器、写寄存器” → 找依赖 → 标产生值的阶段末 → 标消费值的阶段 → 看是否有对应转发路径 → 不够才停顿。

在常见五段模型中，ALU结果EX末可用；load数据MEM末才可用。若下一条紧接着在EX需要load结果，即使有常见转发，也通常仍要停1周期；若图中有特殊路径或不同使用阶段，结论会变化。

示例：常见EX/MEM与MEM/WB到EX转发：

周期 1 2 3 4 5 6 7
lw IF ID EX MEM WB
add IF ID 停顿 EX MEM WB

load在第4周期末得到数据，add第5周期EX使用。若不支持转发，还要按寄存器写回与读取时序重新算，不能照抄一个停顿。

7. 分支、异常与并行概念

分支题先找比较和目标计算在哪一级完成、是否预测、预测失败冲刷哪些年轻指令。停顿和冲刷可能有重叠，不要把几个罚时数字重复相加。

异常由指令执行相关事件引起，例如缺页、非法指令、系统调用等；外部中断由设备或时钟等引起，与当前指令的执行一般异步。返回地址是重做当前指令还是继续下一条，由异常种类和体系结构规定。

超标量关注一周期发射多条指令；多核是多个处理核心；硬件多线程切换或交错线程以利用资源；它们不能互当同义词。

六、总线与I/O

1. 带宽题先找“每次传多少”和“每秒多少次”

数据总线宽度32位，每个100 MHz时钟周期传一次，理论数据带宽 B/s=400 MB/s。若每次事务要4周期且只有一次32位数据传送，则有效数据带宽100 MB/s。若双沿传输或突发传输，以题设有效传输次数为准。

抓三个边界：主频是否就是总线频率；传输周期与时钟周期是否相同；求理论峰值还是包含地址、握手、等待后的有效数据带宽。

同步总线依赖统一时钟约定；异步总线以握手等协调；半同步允许等待。仲裁解决多个主设备争用总线，优先级、响应速度和饥饿等按具体方案判断。

2. 接口不是设备本体，端口不是一根线

I/O接口包含数据缓冲、状态/控制寄存器、地址译码与控制逻辑等；端口通常指其中可寻址寄存器。CPU通过读状态、写控制、读写数据与外设交互。

图源：强化讲义PDF第206页。按线读：地址线选寄存器，数据线传数据，控制线说明读写和状态协调。DMA传输期间，由获总线控制权的相应主设备提供主存地址，不应理解为每个数据字仍由CPU发起普通load/store。

3. 查询、中断、DMA的比较

方式 CPU什么时候参与 数据通常怎样搬
程序查询 主动反复检查状态 CPU执行I/O指令/读写操作
中断 发起后可做其他事，设备就绪再服务 CPU在服务程序中搬运，按题设
DMA 初始化、结束处理与异常等 DMA硬件组织设备接口与主存间传输

DMA不是“完全不需要CPU”，也不意味着“总线和主存不会被占用”。中断方式允许CPU与设备准备过程并行，但CPU执行中断服务本身仍占用处理时间。

先统一为“每秒多少次服务/传输”。设备速率 B/s，每次处理 B：

每次服务耗CPU周期，CPU频率：

例： R=1 MB/s，接口缓冲4 B，一次中断占100周期，CPU为100 MHz；按十进制MB，CPU占用。若缓冲改成每次处理整个块，请求率要按块重新计算。

定时查询：为不丢数据，最坏查询间隔不能超过缓冲可承受的数据到达间隔。先算多久产生字节，即；再看一次查询消耗多少时间、CPU需分配多大比例。

DMA：分清每次DMA请求传一个字，还是每块DMA结束才发一次中断。块大小决定结束中断频率；每次传输粒度决定DMA请求次数，两者通常不同。

5. 中断流程与优先级

常见流程可整理为：检测并响应 → 保存断点/必要状态并转入入口 → 软件保存需保护的现场 → 服务 → 恢复现场 → 中断返回。哪部分硬件完成、哪部分软件完成、是否开中断，依体系结构和题设。

中断响应优先级决定同时请求先响应谁；处理优先级体现处理中谁能打断谁。两者不必相同。

屏蔽字题先确认“1表示屏蔽还是允许”，再对当前服务程序列出允许抢占的集合，画嵌套栈。每次新中断先判断是否允许和是否到响应时点；服务结束按后进先出返回，不按到达时间随意跳转。

6. 磁盘题的三个时间

转速 rpm，一圈秒；均匀随机到达假设下，平均旋转等待半圈。传输时间按传输字节数/对应速率求；只求一个扇区时可结合每圈扇区数计算。

容量通常为盘面数×每面磁道数×每道扇区数×每扇区数据字节数。盘片双面、是否有保留面、地址信息是否计入有效数据容量，逐项看题设。

七、综合题解题步骤

1. 用一行C代码把知识串起来

分析顺序如下：

  1. 语义与类型： i、sum、元素多宽，有无符号，是否发生类型转换？
  2. 地址： a的基址、元素步长、端序和对齐条件是什么？
  3. 指令：哪些指令算地址、读数据、相加、控制循环？
  4. 存储：这些是虚拟地址还是物理地址，跨了哪些页和Cache块？
  5. CPU：哪些指令有依赖，数据何时可用，有无停顿？
  6. 性能：实际执行多少条、多少次缺失、额外几个周期，最后换算时间。

地址、位型、块号和周期数是各小问之间共用的中间量。

2. 综合题计算表

题型 草稿表列名 作用
类型与位运算 步骤、类型、位宽、位型、真值、标志 防止把编码与真值混用
存储访问 地址、VPN/PPN、块号、组号、Tag、命中、代价 防止漏访问和错映射
CPU/流水线 指令、读写集合、阶段、资源、停顿 防止只凭“有依赖”猜周期

3. 计算过程与单位

先写关键假设与单位，再写通用关系，再代数值，最后给结果与含义。例如：“按字节编址，块大小64 B，所以低6位为块内偏移；数据容量16 KiB、4路，得64组，所以组号6位，Tag20位。”
