计算机组成原理：跨章自测：题目与完整解答

题目区

题1：改指令数后，CPI应如何加权

同一任务原执行条指令：A类60%、每条1周期；B类25%、每条2周期；C类15%、每条4周期。主频2 GHz。新方案把每条C类替换为两条A类指令，其他不变、主频不变，无额外开销。求原时间、新指令数、新平均CPI、新时间和加速比。

题2：一个条件判断中有两次不同的转换

int 32位、short 16位。unsigned short x=65535; int y=-1; unsigned int z=1; 判断x+y的类型与值，以及y<z结果。再判断unsigned short r=x+2;的最终值。写出提升与赋值发生在哪一步。

题3：两级Cache的局部率和全局率

所有请求先查L1，耗时2 ns，缺失率10%；L1缺失再查L2，耗时10 ns，L2局部缺失率20%；L2缺失再访问主存，额外80 ns。所有阶段串行，不考虑回写。求平均访问时间、全局主存访问率、L2服务命中的全局比例。

题4：一次跨页读取能否得到连续物理地址

按字节编址，页大小4 KiB，VPN0→PPN3，VPN1→PPN8，均驻留；一次读取4 B，从虚拟地址0x0FFE开始。物理Cache块64 B。求四个字节的物理地址和涉及的Cache块首址。不要求推断具体CPU怎样拆成总线事务。

题5：调度一条独立指令消除停顿

五段流水、完整EX转发，load数据MEM末产生，ALU结果EX末产生，下一周期可用；无其他冒险。

I3与前两条无数据、异常顺序等限制，题目允许将它提前。原序列需几周期？怎样调度可减少一拍？列出各条EX周期。

题6：微指令字段与控存容量

互斥微命令分3组，每组分别8、6、2条；每组包含不发命令状态，不同组可并行。采用字段编码，另有10位下地址、3位条件选择。控存1024字。求操作控制字段位数、微指令总字长、控存容量。解释8条命令为什么不是3位就够。

题7：接口缓冲是否够，CPU开销是否可承受

设备产生8 MB/s数据，每4 B一字；单字缓冲。CPU200 MHz，每次中断从请求到读走数据最坏150周期，持续服务每字需100周期，其他阻塞均已计入最坏值。判断单字接口是否满足最坏期限，长期CPU服务占比多少。若改DMA，长期平均每4 KiB完成一块，CPU每块管理400周期，管理占比多少？数据传输总线开销另计。

题8：分支处罚与数据缺失共同影响时间

一个长程序执行条指令，基础CPI=1.1，主频1 GHz。20%为分支，分支预测错误率5%，每次错误额外3周期；25%指令各有一次数据读取，数据缺失率4%，每次额外40周期。题设规定两种额外开销互不重叠、基础CPI均不含它们，忽略充排。求总周期、时间；若只将数据缺失率减半，加速多少？

解答区

题1解：先统计总周期，再重新分母

原平均CPI=0.6×1+0.25×2+0.15×4=1.7，时间 s。

新A类数量=(0.6+2×0.15)N=0.9N，B类仍0.25N，新总数1.15N；总周期0.9N×1+0.25N×2=1.4N。新平均CPI=1.4/1.15≈1.21739，新时间0.07 s，加速1.7/1.4≈1.21429。

典型错法：用原60%、25%、15%给新CPI加权，比例已经不对应新指令流；或者指令数增加就认定更慢，忽略每条周期减少。

题2解：写出每个阶段的类型

x在加法中提升为int，65535+(-1)=65534，结果int。y<z中int与unsigned int混合，y转为4294967295，因此比较为假，结果int的0。x+2先在int中得到65537，再赋给16位unsigned short，按模65536得1。

验算： 65537=65536+1；无符号赋值截掉高位后为1，但不能据此把前面的加法也称为16位运算。

题3解：后级局部率要乘到达该级的概率

平均时间 ns。主存访问率0.1×0.2=2%；L2命中服务比例0.1×0.8=8%。L1命中90%、L2命中8%、主存服务2%，三条互斥路径和为100%。

也可按路径算：0.9×2+0.08×12+0.02×92=4.6。两种方法交叉检查。不能把L2的20%当成所有CPU请求中20%访问主存。

题4解：跨页后映射可以不连续

前两个字节VPN0、偏移0xFFE与0xFFF，物理地址0x3FFE、0x3FFF；后两个字节VPN1、偏移0与1，物理地址0x8000、0x8001。清低6位得到Cache块首址0x3FC0、0x8000。

必须至少处理两个页映射和两个数据块。若其中第二页不驻留，还会触发缺页；起始页有效不保证整次访问都可完成。具体异常后的状态与重启行为仍由ISA规定，此处不计部分写入等实现细节。

题5解：独立工作填掉load-use间隔

原顺序I1在周期3 EX、周期4 MEM；I2原定周期4 EX但数据太晚，停1拍，到周期5 EX；I3周期6 EX。三条共3+4+1=8周期。

改为I1、I3、I2：EX依次周期3、4、5。I2周期5从MEM/WB取得load结果，无停顿，最后周期7完成。减少的不是依赖本身，而是用独立指令覆盖了必须等待的时段。若I3有与I2的别名、异常或数据顺序限制，就不能擅自移动；题目已明确允许。

题6解：先给每组预留空操作

ceil(log2(8+1))=4，ceil(log2(6+1))=3，ceil(log2(2+1))=2，控制字段9位。总长9+10+3=22位，容量1024×22=22528 bit=2816 B。8条命令加空状态共9种，3位仅8种不够。

无额外对齐时按22位每字计容量；若题目规定按字节或32位对齐存储，再计算实际物理占用，不能无条件把22位向上取整成32位。

题7解：及时性与平均开销分别检验

每字到达间隔4/(8×)=0.5 μs；最坏读走时间150/(200×)=0.75 μs，超过期限，单字缓冲不能保证不丢数据。长期中断频率每秒200万，服务100周期共2亿周期，占100%。即使把一次最坏响应缩短，长期也没有给其他任务和额外开销留下余量。

DMA管理占比，即0.390625%。这只是CPU管理开销；能否持续搬运8 MB/s，还需总线和控制器数据路径带宽满足要求。

题8解：按每条指令的额外周期统一加总

分支额外CPI=0.2×0.05×3=0.03。数据缺失额外CPI=0.25×0.04×40=0.4。总CPI=1.53，总1530000周期，时间1.53 ms。

缺失率减到2%后，数据停顿变0.2，总CPI=1.33，时间1.33 ms，加速1.53/1.33≈1.15038。不能把“缺失率减半”直接解读为整个程序快一倍。
