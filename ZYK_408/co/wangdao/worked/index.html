王道重点题：思考过程与逐步解答

以下题目根据你提供的2027王道教材整理，保留节号、题号与书内页码；题意作精简转述，详细原题与教材解析见习题目录。字母答案以该版选项为准；计算结果和推理可独立核对。

1. §1.3 选择05：速度比与时间比（第13页）

**题意：**同一程序在A、B上分别20s、16s，比较性能。

**怎样想：**先固定“同一任务”，性能与执行时间成反比。不要看到20/16就写A快。

计算：，B的速度为A的1.25倍，选B。B的用时是A的0.8倍，减少20%；速度提高25%。两个百分比的分母不同。

**验算：**更快的B确实花更少时间。只说“快1.25倍”可能有歧义，写成“速度为1.25倍”。

2. §1.3 选择06：主频与总周期同时变化（第13页）

**题意：**A为800MHz，程序12s；B需原来1.5倍周期，希望8s完成。

**怎样想：**题目改变的是总周期，直接用，无须硬拆指令条数与CPI。

**计算：**原总周期；；，选D。

**验算与变式：**若周期不变才是1.2GHz；若B周期翻倍则需2.4GHz。提高主频并不保证同比提速。

3. §2.1 选择01—02：进制与无符号范围（第27页）

**题意：**十进制137.5转十六进制；16位无符号整数范围。

**步骤：**137=8×16+9，整数部分89H；0.5×16=8，小数部分.8H，故89.8H，选A。16位共有种位型，从0计数到，范围0—65535，选B。

**为什么：**65536是不同数值的个数，不是最大值；小数十进制.5不是十六进制.5。

4. §2.2 选择04：补码取负的特殊值（第44页）

**题意：**哪一个8位整数位型取补得到的自身负数编码与原位型相同：80H、90H、B0H、C0H？

**怎样想：**从模运算寻找，等价2x为256的倍数。候选中只有80H。

**位运算：**80H取反7FH，加1回到80H，选A。它表示−128，正128无法用8位补码表示，因此不能据“位型相同”说数学上−128=128。

5. §2.2 选择06：补码位宽与十六进制加法（第44页）

**题意：**两个补码数7E5H与4D3H相加，求结果。

**怎样想：**三位十六进制对应12位。不能见到补码就按8位截断。

**计算：**7E5H+4D3H=CB8H，选C。若按12位有符号数解释，两正数2021+1235=3256超过最大2047，机器位型CB8H表示3256−4096=−840，OF=1。没有超过12位无符号最大4095，CF=0。

**验算：**两个正数相加出现负结果，符合正溢出的判据。

6. §2.3 选择05：IEEE754按字段解码（第61页）

**题意：**单精度位型41A4C000H的真值。

**怎样想：**十六进制先展开，符号位与阶码不按整字节边界切。

**步骤：**符号0；阶码10000011为131，真实指数4；尾数为1.010010011₂。，乘得到20.59375，选D。

**验算：**阶码4意味着正值在16—32之间，可先排除符号错误及明显数量级错误的选项。

7. §3.2 选择01：芯片地址与数据引脚（第87页）

**题意：**SRAM容量1024×8位，求地址线和数据线总数。

**步骤：**1024个单元需要10根地址线；每单元8位需要8根数据线；总计18，选C。不含片选、读写、电源引脚。

**变式：**DRAM若行列地址复用，外部地址引脚可少于总地址位数，所以“容量的对数”不能无条件当地址引脚数。

8. §3.3 选择01：先位扩展、再字扩展（第99页）

**题意：**16K×1芯片组成64K×8，字方向与位方向各扩展多少倍？

**步骤：**深度64K/16K=4，位宽8/1=8，故字扩展4倍、位扩展8倍，选D。实际芯片32片。先把8片共地址并成16K×8，再做4组选片。

**验算：**32×16K×1=64K×8位。题问两个扩展倍数时不要只写32。

9. §3.3 选择04：容量单位由位换字节（第99页）

**题意：**16片2K×4芯片组成多大字节容量？

**计算：**16×2K×4bit=128Kbit=16KiB，选A。若要画连接图，还需给出目标字宽；单算总容量无需假设所有芯片都并成64位数据。

10. §3.5 选择03：Cache命中率反求（第117页）

**题意：**Cache2ns，主存40ns，平均访问3ns，先查Cache，未命中再访主存。

**步骤：**命中耗2ns，未命中耗42ns。，得到h=97.5%，选C。

**怎样验：**h接近1，均值应该很接近2ns。若把未命中总时间当40ns，则是在改题目的串行访问模型。

11. §3.5 选择04—05：写策略先看命中还是缺失（第117页）

**题意：**区分全写、回写与写分配/非写分配；安全性要求不允许任何数据不一致，选择写策略。

**推理：**全写与回写决定写命中时怎样更新下层；写分配与非写分配决定写缺失是否调块。它们是两个维度。选择04的正确叙述是写命中可采用全写或回写，选A。选择05中追求性能的常见配置用回写，要求每次更新立即同步到主存的教材模型用全写，选C。

**条件变化：**真实系统全写若有写缓冲，仍需考虑缓冲排空与可见性；教材抽象题按给定一致性模型判断。

12. §3.6 选择03、05：缺页由谁处理（第135页）

**题意：**页式/段页式主存与外存交换单位；哪类事件需要操作系统缺页处理。

**推理：**页式与段页式均以页进行主外存交换，选择03选D。查TLB未命中可继续查页表，不必缺页；页表确认目标页不在主存，才需缺页异常处理，因此“缺页处理”题选操作系统，选择05选D。

**验算：**把TLB想作页表项的缓存；缓存里没有某项，不能证明映射目标不在内存。

13. §4.3 选择01：16位add的目的寄存器和标志（第181页）

**题意：**AX=FFE8H，BX=7FE6H，执行Intel顺序的add ax,bx。

**步骤：**目的为AX。FFE8H+7FE6H=17FCEH，截16位得7FCEH；有进位CF=1；结果非零ZF=0；最高位0所以SF=0。补码−24+32742=32718可表示，OF=0。故AX=7FCEH且OF0、SF0、CF1、ZF0，选C。

**为什么：**两源操作数异号，相加不会有符号溢出；不能把最高位进位当OF。

14. §4.3 选择02：sub的借位与有符号溢出（第181页）

**题意：**AX=7FE6H，BX=FFE8H，执行sub bx,ax。

**步骤：**目的BX。FFE8H−7FE6H=8002H，无符号65512≥32742，无借位CF=0；最高位1，SF=1；真实补码−24−32742=−32766在16位范围内，OF=0；ZF=0，选B。

**验算：**8002H按补码读为32770−65536=−32766，与数学结果一致。

15. §4.3 选择03：立即数负数、小端与减法（第181页）

**题意：**自定义sub ax,imm语义为(imm)−(ax)，编码2Dxxxx，立即数−3且AX=7，立即数按小端排列。

步骤：−3的16位补码FFFDH，小端两个字节FD FF；整条编码2D FD FF。语义依题设为−3−7=−10，16位可表示，OF=0，选A。

**为什么：**这里是题设自定义语义，不能拿熟悉的x86同名指令覆盖它。字节序只交换字节位置，不能把每个字节内部的位反过来。

16. §4.4 选择01：RISC不靠绝对化断言（第192页）

**题意：**判断RISC是否必用流水线、用了流水线是否必是RISC、是否通常有较多通用寄存器。

**推理：**流水线是实现技术，CISC也可采用；指令集分类不保证某个具体实现一定流水化。“RISC通常有较多通用寄存器”符合教材，选D。RISC格式规则有利于实现，不等于任何程序都更快。

17. §5.2 选择11：中断检查时点（第205页，2011统考）

**题意：**不考虑Cache和预取，CPU处于开中断，判断指令执行描述。

**思考：**区分一条指令的执行过程中访存、时钟周期，以及结束时检查中断。不要把“某个特定指令执行结束才检查”当成通则。教材错误项D；在模型允许响应的指令边界检查外部中断，并非只在程序转移指令结束时检查。

18. §6.2 选择20：非突发总线读块（第288页，2023统考）

**题意：**64位数据总线，1GHz；地址传送1周期；每次64位数据主存准备6ns；不支持突发；块32B。

**步骤：**周期1ns；每次8B，需4次。每次地址1ns+准备6ns+数据1ns，共8ns；整块32ns，选D。

**易错：**若只付一次寻址/准备，就偷偷引入了突发或流水条件。题目专门给“不支持突发”就是约束。

19. §7.3 例7.2：是否能使用单字中断（第300页）

**题意：**CPU500MHz、CPI4；设备40MB/s；缓冲32bit；每次中断至少400周期。

**步骤：**每0.1μs来4B，服务每次至少0.8μs，CPU跟不上。请求率/s，若逐字中断，CPU所需周期/s，高于可用/s，需求占800%，不能持续处理。

**验算：**从单次时间与每秒负荷两条路线得到相同结论。400已是周期，不应再乘CPI。增大缓冲或DMA改变模型后需重新算。

20. 把一道综合题拆成可检查的中间量

这是一道自编变式，不是王道原题。32位物理地址；Cache数据区16KiB，32B块，2路；按字节编址，初始空，LRU。顺序访问字节地址0、32、8192、0、16384、8192，每次只读1B。

**先想地址：**512行、256组；偏移5位、组号8位、Tag19位。块号为0、1、256、0、512、256；组号为0、1、0、0、0、0。

**再模拟状态：**仅写目标组，括号内从最近到最久。

访问 组 结果 该组访问后块号顺序 原因
0 0 缺失 (0) 冷启动
32 1 缺失 (1) 另一组，不能占第0组空行
8192 0 缺失 (256,0) 第0组第二路空闲
0 0 命中 (0,256) 更新LRU
16384 0 缺失 (512,0) 替换最久未用256
8192 0 缺失 (256,512) 替换最久未用0

**最后验算：**共6次，命中1次，命中率1/6；容量虽然远大于3个块，仍会因为映射到同一组而冲突。把2路当“全Cache任意放两行”，会忽略组约束。
